# Welcome to Learn Harness Engineering | Learn Harness Engineering — Digest
## 1. [[wiki/01-welcome-to-learn-harness-engineering|Welcome to Learn Harness Engineering]]
**In one sentence:** Learn Harness Engineering is a course on engineering AI coding agents that makes tools like Codex and Claude Code reliable through systematic environment design, state management, verification, and control systems.
## Key points
- The course synthesizes advanced Harness Engineering theories and practices, with four core references: OpenAI on Codex in an agent-first world, two Anthropic guides on long-running agents, and Awesome Harness Engineering.
- A harness does not "make the model smarter"; it establishes a closed-loop working system for the model.
- The course teaches constraining the AI coding assistant with explicit rules and boundaries to build features, fix bugs, and automate development tasks.
- Learning paths are split into theoretical lectures, hands-on projects, and a copy-ready resource library.
- Key concepts taught include constraining agent behavior, maintaining context across long-running multi-session tasks, and stopping agents from declaring victory too early.
- Verification is taught via full-pipeline tests and self-reflection, plus making runtime observable and debuggable.
- Next steps point to Lecture 01 (Why Capable Agents Still Fail), Project 01 (Baseline vs Minimal Harness), and templates (AGENTS.md, feature_list.json, claude-progress.md).
## The argument in five moves
1. Strong models alone are not enough — reliability comes from engineering the system around the model, not from making the model smarter.
2. That system is the harness: a closed-loop working environment built on environment design, state management, verification, and control.
3. The course grounds this in industry practice by synthesizing four core references from OpenAI, Anthropic, and Awesome Harness Engineering.
4. It teaches the mechanism through theory (why capable agents fail), practice (building a minimal harness), and reusable templates (AGENTS.md, feature_list.json, claude-progress.md).
5. The payoff is constrained, observable, verifiable agents that sustain context, resist premature victory claims, and reliably build features, fix bugs, and automate development tasks.
