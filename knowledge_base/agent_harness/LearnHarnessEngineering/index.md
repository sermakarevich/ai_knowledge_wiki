# Welcome to Learn Harness Engineering | Learn Harness Engineering

This folder covers the welcome page of Learn Harness Engineering, a course on making AI coding agents reliable through systematic harness design. The core idea is simple: reliability comes from the system around the model — environment, state, verification, and controls — not from a smarter model.
