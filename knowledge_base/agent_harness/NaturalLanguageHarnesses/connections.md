# Connections

- [[OsmaniHarness/summary|Agent Harness Engineering]] — Same core claim from a practitioner angle: Osmani's "agent = model + harness" and his generator/evaluator split, ratchet, and context-rot defences are exactly the kind of harness policy this paper proposes externalizing into a readable NLAH document instead of leaving it as ad-hoc code/prompt conventions; where Osmani gives qualitative practice advice, this paper gives a measurable runtime and ablation methodology for the same ideas.
- [[ModelOrHarnessFailureTaxonomy/summary|Model or Harness? An Interaction-Centric Taxonomy for Localizing Agent Failures]] — Direct complement: that taxonomy labels failures by which interaction edge (User/Harness/Environment) and endpoint is at fault, while this paper's own worst-measured mechanism — parent-child Information Handoff Recall of 0.32–0.55 — is precisely a Harness-edge failure in that taxonomy's terms; running the taxonomy's judge protocol over IHR-executed traces would give a finer-grained diagnosis of why handoff recall is low.
- [[PrimeAgentSelfImprovingHarness/summary|Prime Agent: A Self-Improving RLM Harness]] — Contrasting design point on the same "separate the model from the harness" axis: Prime Agent keeps the harness as a persistent, self-improving code substrate (L0-L3 caches, recursive subagents) that accumulates state across runs, whereas NLAH+IHR keeps the harness as a static, human-readable document interpreted fresh each run — Prime Agent optimizes for compounding capability, this paper optimizes for inspectability and portability, and neither addresses the other's target property.
- [[React/summary|ReAct]] — Historical precursor at the mechanism level: ReAct's interleaved thought/action/observation loop is one instance of the "agent call" unit this paper formalizes (`y = LM_m(c)` over an evolving context with tool feedback); NLAH+IHR generalizes the idea by moving the *policy* about when to think, act, validate, and stop out of the prompt template and into an externally editable, runtime-interpreted document.
