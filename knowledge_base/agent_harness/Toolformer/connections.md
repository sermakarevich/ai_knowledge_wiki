# Connections

- [[React/summary|ReAct: Synergizing Reasoning and Acting in Language Models]] — Complementary tool-use mechanisms with opposite tradeoffs: Toolformer learns *when to call a fixed tool* via self-supervised finetuning (no per-task prompting, but one call per input, no chaining), while ReAct interleaves free-form reasoning with actions via in-context prompting on a frozen model (supports arbitrary multi-step chaining and interactive search refinement, but needs hand-written thought demonstrations per task). Toolformer's single-call ceiling — its inability to do date-then-lookup on TempLAMA — is exactly the class of problem ReAct's explicit subgoal-tracking thoughts are designed to solve.
- [[Reflexion/summary|Reflexion: Language Agents with Verbal Reinforcement Learning]] — Both papers teach an LM new behavior without updating its weights at test time, but at different loops: Toolformer's self-supervision happens once, offline, via loss-filtered finetuning on tool calls, producing a model that decides tool use zero-shot; Reflexion instead reinforces behavior per-episode through verbal self-reflection stored in memory, with no finetuning at all. A system could combine them — a Toolformer-style finetuned tool-caller whose failures are diagnosed and corrected via Reflexion-style episodic self-critique.
- [[AgentSkillsCanBeHarmful/summary|Agent Skills Can Be Harmful]] — Cautionary counterpoint: Toolformer's loss-based filter is validated only by whether a kept call reduces perplexity in isolation, not by whether the resulting tool-calling habit is safe or cost-effective in deployment; this paper's empirical finding that loaded agent skills frequently cause failures and cost regressions in practice is a reminder that "the model learned to call this tool" (Toolformer's success criterion) and "calling this tool is a good idea in production" (this paper's concern) are different questions that Toolformer's evaluation does not address.
