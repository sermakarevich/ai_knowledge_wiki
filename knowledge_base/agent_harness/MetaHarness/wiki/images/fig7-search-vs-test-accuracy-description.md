**Figure 7 — Val vs. Test Accuracy by Dataset (gpt‑oss‑120b)**

**What it shows.** A three‑panel scatter plot comparing validation‑set accuracy against test‑set accuracy for each of the three text‑classification datasets (LawBench, Symptom2Disease, USPTO), under the gpt‑oss‑120b model. In each panel, individual pink dots are the autonomously *discovered* prompting strategies, while a handful of darker labeled markers are fixed baselines (zero‑shot, various few‑shot prompt lengths, and the manually authored "AIC" harness). A dashed diagonal in each panel marks the line y = x, i.e., perfect agreement between val and test.

**Axes.** Both axes are accuracy in percent. The x‑axis is Val Acc (%) and the y‑axis is Test Acc (%). The ranges differ per dataset: LawBench and USPTO span roughly the low single digits up to about 50% and ~30% respectively, while Symptom2Disease is in a higher band (roughly mid‑50s to low‑90s), reflecting the differing difficulty of each task.

**Trends.** In all three panels the points form a loose cloud centered on the y = x diagonal, indicating that validation accuracy tracks test accuracy reasonably well — a configuration that does well on the search/val set tends to do well on the held‑out test set, with some scatter (a few points above or below the diagonal). Baselines cluster in the lower‑left region of each panel, whereas several discovered (pink) configurations reach the upper‑right, i.e., higher val *and* higher test accuracy. The pattern of agreement is qualitatively similar across datasets, though the absolute accuracy levels differ.

**Takeaway.** Validation accuracy is a usable proxy for test accuracy for these discovered strategies across all three datasets (the points hug the y = x line), so the search‑time val objective is a trustworthy stand‑in for held‑out performance. At the same time, the discovered strategies generally reach higher accuracy than the simple zero‑shot/few‑shot baselines, confirming that the autonomous search finds configurations that improve both val and test outcomes.
