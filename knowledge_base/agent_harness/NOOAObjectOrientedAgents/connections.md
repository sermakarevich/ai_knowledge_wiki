# Connections

- [[CodeAsAgentHarness/summary|Code as Agent Harness]] — builds-on/same-paradigm: this survey formalizes "code as agent harness" — code as an executable, inspectable, stateful operational substrate rather than a mere output — organized into harness interface, harness mechanisms, and multi-agent scaling layers; NOOA is a concrete, opinionated instantiation of exactly that thesis, unifying code-as-action, pass-by-reference over live objects, and model-callable harness APIs into ordinary Python classes (see [[wiki/01-introduction-and-design-principles|Introduction & Design Principles]]).
- [[agent_harness/SemaClaw/summary|SemaClaw: A Step Towards General-Purpose Personal AI Agents through Harness Engineering]] — same-problem-different-method: both papers argue harness design, not model choice, is the main lever on capability (SemaClaw measures +13.7pp from harness changes alone with the model held fixed; NOOA measures a 6.4x harness effect on ARC-AGI-3), but SemaClaw's harness is a multi-agent DAG orchestration layer with a PermissionBridge runtime-safety checkpoint and a three-tier Markdown-plus-vector memory, versus NOOA's single typed-object agent with a SQLite/ACT-R memory graph — a natural-language multi-agent harness vs. a Python single-agent typed harness solving the same problem.
- [[agent_harness/NemoClawLocalAgent/summary|Build a More Secure, Always-On Local AI Agent with OpenClaw and NVIDIA NemoClaw]] — same-lab, complementary layer: both are NVIDIA agent-infrastructure releases from mid-2026 addressing different layers of the same stack — NemoClaw packages sandboxed local deployment (OpenShell + OpenClaw + Nemotron 3 Super) with interactive network/filesystem policy approval, while NOOA is the programming-model layer (agent-as-Python-class) such a deployment would run; NOOA's own untrusted-code containment for the ARC-AGI-3 fleet (Landlock, seccomp, per-cell OS sandbox — see [[wiki/06-arc-agi-3-and-world-models|ARC-AGI-3 & World Models]]) echoes NemoClaw's sandboxing concerns at the execution layer.
- [[AreWeReadyForAnAgentNativeMemorySystem/summary|Are We Ready For An Agent-Native Memory System?]] — same-problem-different-method: this paper benchmarks 12 memory architectures (including Letta, which NOOA's own Appendix C Table 8 also compares against — see [[wiki/03-execution-validation-and-memory|Execution, Validation & Memory]]) across representation, extraction, retrieval, and maintenance modules and concludes no single architecture dominates across workloads; NOOA's own memory subsystem is one point in that design space — a single SQLite file with ACT-R activation and typed pass-by-reference records — and its comparison table makes the same "no dominant design, only different tradeoffs" argument this survey formalizes at benchmark scale.
- [[RethinkingMemoryContinuouslyEvolvingConnectivity/summary|Rethinking Memory as Continuously Evolving Connectivity]] — shares-technique: FluxMem models memory as a dynamically-edited heterogeneous graph across semantic/episodic/procedural layers with online link refinement and offline consolidation into reusable procedures; NOOA's memory subsystem independently converges on a structurally similar design — a typed memory graph over info/skill/episode/todo/reflection records, activation spreading, and an asynchronous reflection pass that merges duplicates, reconciles conflicts, and prunes by decay (see [[wiki/03-execution-validation-and-memory|Execution, Validation & Memory]]) — though NOOA drives retrieval with an ACT-R cognitive model rather than FluxMem's feedback-driven connectivity edits.
- [[CanLLMAgentsInferWorldModels/summary|Can LLM Agents Infer World Models? Evidence from Agentic Automata Learning]] — contrasts/complements: this paper finds frontier LLM agents cannot reliably infer a hidden world model (a DFA) from pure interaction — under 25% success on 8-9 state automata vs. 100% for classical algorithms — with failures traced to disorganized evidence integration; NOOA's headline ARC-AGI-3 result gets its 6.4x harness effect precisely by *not* asking the model to infer dynamics unaided, instead scaffolding world-model construction as an explicit skill (`encode`/`predict`/retrodiction, see [[wiki/06-arc-agi-3-and-world-models|ARC-AGI-3 & World Models]]) — consistent with the automata-learning paper's implication that raw LLM world-model inference is exactly the bottleneck a harness needs to compensate for.
