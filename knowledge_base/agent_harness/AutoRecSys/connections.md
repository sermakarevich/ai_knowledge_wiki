# Connections

- [[research/NaturalLanguageHarnesses/summary|Natural-Language Agent Harnesses]] — Same-mechanism-different-domain: NLAH externalizes agent-harness policy into editable natural-language documents run by a shared Intelligent Harness Runtime; Auto-RecSys's cognitive-procedural separation and per-model playbooks are the same idea (natural language steers reasoning, code enforces mechanics) specialized for multi-day recommender training rather than coding/terminal/computer-use benchmarks.
- [[research_topics/agent_harness/AgenticHarnessEngineering/summary|Agentic Harness Engineering]] — Shares-technique: AHE auto-evolves a coding-agent harness by observing trajectories and rewriting the harness itself, closely mirroring Auto-RecSys's Execution Evolution Loop (distill session trajectories into per-model playbooks and dead-end catalogs) — AHE evolves generic coding harnesses via a +7.3pp benchmark score, while Auto-RecSys evolves domain-specific playbooks via a falling operational-fix rate.
- [[research_topics/agent_harness/UltraLongHorizonAgenticScience/summary|Toward Ultra-Long-Horizon Agentic Science]] — Same-problem-different-scale: ML-Master's Hierarchical Cognitive Caching runs 24-hour Kaggle ML tasks via accumulated memory, addressing the same long-horizon-feedback problem as Auto-RecSys but at hours-scale competition tasks rather than days-scale industry training with fragile distributed infrastructure and evolving baselines.
- [[research/AmuxHarnessGuide/summary|Harness Engineering: The Complete Guide]] — Applies-in-practice: the "Agent = Model + Harness" framing and the ratchet principle (every failure becomes a permanent rule) describe in general terms exactly what Auto-RecSys's dead-end catalog does concretely for recommender training failures — GPU instability, package-layer mismatches, expired checkpoints each become a "DO NOT" rule that fires once and then disappears.
- [[research/HarnessEngineeringCourse/summary|HarnessEngineeringCourse]] — Same-problem-different-angle: the course teaches individual harness primitives (memory, orchestration, subagents, verification) as isolated chapters for a single-session coding agent, while Auto-RecSys shows what several of those primitives look like combined and scaled up for a persistent, multi-server, multi-week research system.
