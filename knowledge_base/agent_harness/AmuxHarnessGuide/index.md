# Harness Engineering: The Complete Guide

amux.io's guide to harness engineering: an AI agent equals a commodity model plus an engineered harness (guides that steer before action, sensors that validate after), and harness design — not model choice — determines production performance. Covers the guides/sensors cybernetics vocabulary, the ratchet principle for permanently fixing agent mistakes, a six-way failure-to-fix routing table, lean CLAUDE.md practice, and scaling the same architecture to multi-agent orchestration platforms such as amux (the guide's own product).
