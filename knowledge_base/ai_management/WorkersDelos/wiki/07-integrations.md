# Integrations
**In one sentence:** AI Workers connect natively to Slack, Microsoft Teams, Gmail, Notion, HubSpot, Salesforce, and 3000+ other tools with no-code setup in under 5 minutes, working where your team already works under granular per-tool permissions.
## Key points
- Workers connect natively to Slack, Microsoft Teams, Gmail, Notion, HubSpot, Salesforce, and 3000+ other tools, working where the team already works with no new tool to adopt.
- Setup takes less than 5 minutes with no code: connect via OAuth (an industry login standard that grants access without sharing passwords) in a few clicks, define read/write scope, and the worker starts.
- Messaging: Slack, Microsoft Teams, Gmail, Outlook — workers receive requests, reply, notify, report in channels, monitor a channel, handle requests, and escalate to a human when needed.
- Productivity and docs: Notion, Google Drive, Confluence, Google Docs — workers read reference documents, write summaries, update knowledge bases, and keep documentation current automatically.
- CRM (customer relationship management) and sales: HubSpot, Salesforce, Pipedrive — workers enrich contacts, qualify leads, prepare email sequences, and keep the pipeline clean.
- Project and dev work: Jira, Linear, GitHub, GitLab, Asana, Trello — technical workers open tickets, comment on pull requests, track sprint progress, and flag blockers.
- Every integration respects granular permissions tool by tool, revocable at any time; no data trains models; connections use vendors' standard OAuth with no password storage; missing tools can go via webhooks or API (contact Delos).
