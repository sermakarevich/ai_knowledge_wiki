# Use Cases — Marketing, Dev, HR, Finance

**In one sentence:** The catalog documents more than 200 concrete use cases pairing each recommended worker with automated tasks and expected time savings, filterable by role, tool, and autonomy level, starting from high-impact low-effort wins.

## Key points

- More than 200 concrete use cases show how teams use AI Workers every day.
- Each use case details the recommended worker, the automated tasks, and the expected time savings.
- Each use case also documents measured ROI (Return On Investment — what you gain versus what you spend) and integration prerequisites.
- You can filter by role, by tool, or by level of autonomy (supervised or autonomous).
- The recommended rollout: start with a high-impact, low-effort use case, then gradually expand worker scope.
- Functions covered: marketing, development, customer support, HR, finance, data, SEO, design, and project management.
- Named tools include HubSpot, GitHub, GitLab, Linear, Jira, Intercom, Zendesk, Looker, BigQuery, Figma, Asana — plus the site-wide Slack, Teams, 3000+ tools framing.
- The page sits in shared site navigation: 15 AI Workers, pricing, integrations, security and GDPR, tech, build-a-team, clone-yourself, personality, blog, companion extension, and the five solution agents.
