# mateaix/mateclaw

MateClaw v2.3.0 is a self-hosted, pluggable agent runtime ("second brain") that runs digital employees over native StateGraph or DSH engines with multi-provider failover, linked wiki knowledge, and durable Goals and Team Runs in one deployment. This folder holds a 2-minute summary, a 10-minute digest, plain-language and critical takes, retrieval questions, and two wiki pages.
