# siddsachar/row-bot

Row-Bot is a local-first desktop AI assistant for doing real work with models, memory, and tools. Its operating model is Reason through messy context, Orchestrate tools and providers, and Work inside user-chosen files, repos, workflows, and channels. This folder holds a summary, digest, plain-language explainer, critical analysis, practice questions, and two wiki pages covering the README identity and the repository root.
