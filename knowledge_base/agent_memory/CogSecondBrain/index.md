# huytieu/COG-second-brain

COG (Cognition + Obsidian + Git) is a convention-based second brain: a versioned Obsidian markdown vault operated on by 33 agent skills, 6 worker agents, and 4 read-only verifiers, with Git as the persistence layer. This folder holds a technical summary, a verbatim digest of wiki key points, a plain-language explainer, a critical analysis, retrieval questions, and two wiki pages covering the repo concept and its top-level files.
