# coreyhaines31/makerskills

Makerskills is a documentation-first plugin of 21 AI agent skills for founder and operator workflows — decisions, research, knowledge bases, content, CFO cadence, and domain hunts — running on Claude Code, Codex, Cursor, and other Agent Skills hosts. Each skill is a `SKILL.md` workflow doc following a structured input → structured output → archive-to-disk pattern, with personal data kept in a private on-disk config layer outside the public repo. Start with `summary.md` for the technical picture, then `digest.md` for the verbatim wiki essence.

## How to work through this

1. Read `summary.md` (~2 min) for the technical overview: architecture, skill families, invocation pipeline, and key files.
2. Read `digest.md` (~10 min) for the verbatim essence of each wiki page plus the five-move system summary.
3. Go deep in the wiki pages via the table below, use `explainer.md` for plain-language background, `critical_thinking.md` for claims-vs-evidence scrutiny, and `questions.md` for retrieval practice.
