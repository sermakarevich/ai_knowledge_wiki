# notoriouslab/vault-curate

Vault Curate is a local-first Obsidian plugin (v1.11.0) for semantic search and connection-finding, strong on Chinese/CJK text. Its loop is Find, Connect, Rediscover — fused keyword/semantic/fuzzy search, suggestion-only Canvas relation graphs with verdict-gated wikilinks, and Hot/Cold surfacing of forgotten notes. This folder holds the distilled research: start with the summary, go deeper with the digest, then the wiki pages.
