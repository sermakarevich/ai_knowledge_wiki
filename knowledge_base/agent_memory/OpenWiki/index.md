# kdsz001/OpenWiki

OpenWiki is a privacy-first Tauri 2 desktop app (React 19 + Rust + SQLite) built around an explicit copy-to-keep capture loop with AI-organized wiki, knowledge graph, and weekly attention reports. This folder holds a technical summary, a verbatim digest of the wiki pages, two component wiki pages, plus plain-language, critical, and retrieval-practice companions.
