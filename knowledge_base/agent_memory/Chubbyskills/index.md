# chubbyguan/chubbyskills

Chubby Skills is a set of 14 Agent Skills plus a unified CLI that collects video, podcast, article, and local-doc material into a local Markdown vault. Its core loop — import, keyword search, and sourced brief export — runs on Python stdlib with no API keys, while media paths are dependency-gated. Start with the summary for the pipeline, then the digest and wiki pages for grounded detail.

## How to work through this

1. Read [summary](summary.md) (~2 min) for the pipeline, skill catalog, and data boundaries.
2. Read [digest](digest.md) (~10 min) for verbatim key points per wiki page plus the five-move system recap.
3. Deep-dive the wiki pages in order, then [explainer](explainer.md) for plain language, [critical_thinking](critical_thinking.md) for claims-vs-evidence, and [questions](questions.md) for retrieval practice.
