# Explainer — Unleashing developer productivity with generative AI

## What it is

In June 2023 the consulting firm McKinsey published the results of an in-house experiment: more than 40 of its own programmers were asked to do everyday coding chores, half of them with generative Artificial Intelligence (AI) assistants — tools that write code from a plain-English request — and half without. The article reports how much faster the assisted group was, where the tools helped most, where humans were still essential, and what company leaders should do about it.

## Why it matters

Software runs nearly every business, and programmers are expensive and scarce. If an assistant can genuinely double coding speed without breaking things, that is like hiring a second engineering team for the price of software licenses. But the study also warns the speedup is uneven: it fades on hard problems and can even slow down beginners, so buying the tool without training and safety rules wastes the investment.

## How it works

Think of the AI assistant as a very fast junior colleague who has read millions of programs but knows nothing about your company. It shines at chores it has seen a thousand times: filling in standard code patterns, finishing half-typed lines, writing routine documentation, and drafting a first version so nobody stares at a blank screen. When a task involves unfamiliar code or frameworks, it acts like a tutor that gets the programmer oriented quickly, which is why assisted developers finished complex assignments on time 25 to 30 percent more often. Combining two different assistants — one general chatbot-style helper and one tuned specially for code — multiplied the benefit further.

## Where it is used

The experiment covered the three staples of programming work: creating new code, improving existing code, and writing documentation. The lessons target technology leaders deciding how to roll the tools out across engineering teams: teach everyone to write good requests, give beginners extra grounding in programming basics, steer freed-up time toward design and new products, and set guardrails for privacy, legal, and security risks.

## Takeaways

The core message is that generative AI is a genuine productivity lever for software teams, roughly doubling speed on standard tasks while leaving quality intact and making programmers happier. The catch is that the tool multiplies existing skill rather than replacing it: experts must still catch its mistakes, feed it company context, and judge the hard calls. Capturing the value therefore takes deliberate leadership — training, broader use cases, reskilling, and risk controls — rather than simply handing out licenses.

## Jargon decoder

- Generative AI: software that creates new content, here code, from a natural-language request.
- Prompt engineering: the skill of writing clear requests that get useful answers from an AI tool.
- Code refactoring: restructuring existing code to make it cleaner or faster without changing what it does.
- Integrated development environment (IDE): the editor workspace where programmers write and test code.
- Maintainability: how easily code can later be understood and improved.
- Flow: the focused, satisfying state of being fully absorbed in work.
- General Data Protection Regulation (GDPR): the European Union's strict data-privacy law limiting how personal data is used.
