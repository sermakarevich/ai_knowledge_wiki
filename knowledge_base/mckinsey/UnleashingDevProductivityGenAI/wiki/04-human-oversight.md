# Where humans still matter

**In one sentence:** The tools are only as good as their users, so developers must still hunt AI-introduced bugs, supply project-specific context, and steer the trickier judgments the tools cannot make.

## Key points

- Participant feedback identified three areas where human oversight and involvement were crucial, summarized by the article as proof that tools match the skill of the engineers using them.
- AI assistants sometimes gave wrong coding recommendations and even introduced errors, forcing one developer into many corrective prompts and another to "spoon-feed" the tool to debug correctly.
- Off-the-shelf tools lack knowledge of a specific project's integration needs, performance and security requirements, and end-user goals, so developers must inject that context through prompting.
- Developers must specify how the code will be used and by whom, which interfaces and systems it touches, and what data it uses — details no general model can infer alone.
- A third oversight area, opening with the words "Navigating tricky," was confirmed to exist but its exact content could not be recovered from any retrieved extract.
- Junior developers were the sharpest illustration of the skill dependency, taking 7 to 10 percent longer on some tool-assisted tasks because they lacked the foundations to steer and check the output.

## Three areas of required oversight

### Examining code for bugs and errors

"Research participants reported that, at times, generative AI–based tools provided incorrect coding recommendations and even introduced errors in the code. During one task, a developer noted she had to input numerous prompts to correct a tool's erroneous assumption so she could get an answer to a question. In another case, a developer shared that he had to 'spoon-feed' the tool to debug the code correctly."

### Contributing organizational context

"While off-the-shelf generative AI–based tools know a lot about coding, they won't know the specific needs of a given project and organization. Such knowledge is vital when coding to ensure the final software product can seamlessly integrate with other applications, meet a company's performance and security requirements, and ultimately solve end-user needs." The remedy is explicit: "it will be up to software developers to provide these tools with the context via prompting, including how the code will be used and by whom, the types of interfaces and other systems the software will interact with, the data used, and more."

### Navigating tricky judgments [unverified]

Every retrieved extract truncated this third bullet after the opening words "Navigating tricky," so its precise scope is unconfirmed; it sits alongside debugging and context as the third human-oversight area.

## The skill floor

### Juniors felt it first

The junior-developer result belongs here as well as in the numbers: developers with less than a year of experience took 7 to 10 percent longer with the tools on some tasks. The article's remedy, detailed in the leadership section, is extra coursework in syntax, data structures, algorithms, design patterns, and debugging before productivity gains appear.
