# Where generative AI shined

**In one sentence:** The tools delivered their biggest wins on routine work, first drafts, and code updates, still helped developers push through complex unfamiliar tasks, and left developers markedly happier.

## Key points

- Generative AI expedited manual and repetitive work such as auto-filling standard functions, completing statements as the developer types, and documenting functionality in a standard format from a prompt.
- Facing a blank screen, developers requested suggestions through a prompt window or inside their integrated development environment (IDE) and reported helpful starting points that broke writer's block and brought "flow" sooner.
- Participants making changes to existing code reported faster, larger edits when they prompted the tools effectively.
- On complex tasks the tools helped developers rapidly brush up on an unfamiliar code base, language, or framework, making them 25 to 30 percent more likely to finish within the allotted time (Exhibit 2).
- Developers who used both AI tools on a task, rather than just one, gained an additional time improvement of 1.5 to 2.5 times.
- Developers with AI assistance were more than twice as likely to report overall happiness, fulfillment, and a state of flow, a morale effect the article ties to retaining talent (Exhibit 3).

## Four areas of gain

### Expediting manual and repetitive work

"Generative AI can handle routine tasks such as auto-filling standard functions used in coding, completing coding statements as the developer is typing, and documenting code functionality in a given standard format, based on the developer's prompt."

### Jump-starting the first draft of new code

"When facing a blank screen, developers with generative AI–based tools can request suggestions by entering a prompt in a separate window or within the integrated development environment (IDE) they use to develop software. Developers who did so reported that the generative AI–based tools provided helpful code suggestions. This enabled them to escape writer's block so they could get started more quickly. As one participant shared, the tools enable developers to get in the 'flow' sooner."

### Accelerating updates to existing code

Participants reported that "when using these tools with effective prompting, they could make more changes to existing code faster." The qualifier matters: prompting skill gates the gain.

### Brushing up on the unfamiliar

"While developer time savings with generative AI–based tools were more modest for complex tasks, our research still finds benefits: the technology can help developers rapidly brush up on an unfamiliar code base, language, or framework necessary to get the job done." The payoff showed in completion rates: AI-assisted developers on complex tasks "were 25 to 30 percent more likely than those without the tools to complete those tasks within the time frame given (Exhibit 2)."

## Compounding and morale effects

### Two tools beat one

"When developers used both generative AI tools within a given task, as opposed to only one, they realized an additional time improvement of 1.5 to 2.5 times."

### Happier developers

"The research finds that equipping developers to be their most productive also significantly improves the developer experience, which in turn can help companies retain and excite their best talent. Developers using generative AI–based tools were more than twice as likely to report overall happiness, fulfillment, and a state of flow (Exhibit 3)."

**Covers:** four key gain areas, Exhibit 2 complex-task completion uplift, dual-tool compounding, Exhibit 3 developer-experience effect.
