# Data as a strategic asset

**In one sentence:** The rewired procurement model starts with data because procurement functions use less than 20 percent of available data today, and agents can only exploit the rest once siloes are linked into a common data spine across spend, suppliers, contracts, and market benchmarks.

## Key points

- The authors estimate that today's procurement functions use less than 20 percent of available data for decision-making, which caps both human and agent performance.
- AI agents will help procurement use more of that data, but only provided the data is accessible to them, making accessibility the precondition rather than the afterthought.
- The prescribed path is sequential: first build digital links between existing tools and data, then create a common data spine as the single source of truth across spend, suppliers, contracts, and market benchmarks.
- The data spine must cover four domains together because agent workflows join them continuously, and a gap in any one domain breaks pricing, risk, and compliance reasoning downstream.
- Data is listed first among the four rewired-model shifts because the other three shifts assume agents can reach clean, joined-up data at runtime.
- Treating data as infrastructure rather than exhaust reframes procurement's technology budget from buying tools toward building the shared asset every agent depends on.

---

## The 20 percent diagnosis

"Procurement can no longer afford to operate with fragmented, outdated, or incomplete data," the article states, followed by the estimate that today's functions use less than 20 percent of available data to support decision-making. The number explains why earlier analytics investments disappointed: models trained on a fifth of the evidence cannot price, predict, or negotiate reliably. It also sets the ceiling for agents, since an agent with the same fragmented inputs merely makes the same mistakes faster.

## Accessibility as precondition

The article adds that AI agents will help procurement use more data "provided it is accessible to them." That qualifier carries the implementation warning: agent capability is not the constraint, data reach is. Procurement teams that deploy agents on top of siloed spend cubes, disconnected contract repositories, and external benchmarks nobody joined up should expect confident-sounding outputs built on partial evidence.

## The two-stage remedy

The remedy comes in two stages. First, break down data siloes with digital links between existing tools and data, which delivers connectivity without replacing systems. Then build the common data spine: a single source of truth across spend, suppliers, contracts, and market benchmarks. The spine metaphor matters because every agent workflow draws on all four domains at once — spend tells what was bought, suppliers tell from whom, contracts tell on what terms, and benchmarks tell whether the terms were any good.

## Why data comes first

Among the four rewired-model shifts, data is the load-bearing one. Agent factories assume agents can import from diverse sources, human-agent teaming assumes outputs worth reviewing, and end-to-end integration assumes signals flow from demand to supplier performance. Each of those breaks cleanly at a missing or stale dataset, so the article's sequencing reads as a dependency order rather than a menu.
