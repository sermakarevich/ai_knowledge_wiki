# Four levels of developer support

**In one sentence:** McKinsey grades AI's progress in software as four levels — solo coding, AI-accelerated tasks where most firms sit, AI-automated workflow steps now spreading, and end-to-end application delivery by agent teams promising 20 times leverage but still largely experimental.

## Key points

- Level 1 is developing without generative artificial intelligence (AI), where the developer writes all the code alone with solid quality but speed capped by one person's pace.
- Level 2 speeds up individual tasks like a super-fast pair programmer suggesting the next ten lines, gives a meaningful productivity boost, and is where most companies are today.
- Level 3 automates entire workflow steps from a plain-English feature description to code, tests, and documentation, and adoption is rising as large language models (LLMs) grew from inline completion into long-running multifile refactoring and modernization.
- Level 4 has a small team guiding a coordinated agent system that delivers whole applications end to end while raising only judgment calls to humans, yielding 20 times leverage of a few practitioners doing a large department's work.
- Level 4 is largely experimental as of the book's writing, with promising developments already emerging, so the 20x figure is a frontier claim rather than a measured average.
- The jump that matters is from tool-per-developer at Levels 2–3 to orchestrated multi-agent delivery at Level 4, which demands a redesigned life cycle rather than faster typing.
- Third-party commentators add an unofficial Level 3.5 of parallel agentic coding at roughly 5–10x gains, which is analysis about the article rather than article content.

---

## Level 1: the baseline

Level 1 is developing without generative AI. "The software developer writes all the code alone. Quality is solid, but speed is limited by how fast one person can work." It functions in the article as the control group against which every higher level is measured.

## Level 2: the pair programmer

At Level 2 "the developer writes a few lines, and the AI suggests the next ten, as though you had a super-fast pair programmer sitting beside you," and "AI provides a meaningful productivity boost." The human still drives everything; the machine accelerates keystrokes and recall. Most companies are at this level, which is why industry-wide productivity data still reflects assistance rather than autonomy.

## Level 3: the workflow step

Level 3 automates entire steps: "a developer describes a new feature to the AI agent in plain English" and "the AI generates the first version of the code, the tests, and the documentation automatically," with "very substantial" gains. The enabling mechanism is named explicitly — LLMs evolving "from simple inline completion tools to autonomously executing long-running multifile refactoring and modernization tasks" — so Level 3 spreads exactly where agents sustain context across files and time.

## Level 4: the application factory

At Level 4 "a small team guides a coordinated system of AI agents that can deliver an entire application end to end — from design to code to testing to integration — raising only the decisions that truly require human judgment," and "the result is 20 times leverage." The operative word is coordinated: agents across the full life cycle, humans as exception handlers. McKinsey calls this stage largely experimental, so readers should treat 20x as demonstrated-at-the-frontier ceiling, consistent with the reported 10x at half cost in the bank case, not as a planning factor for a typical team.

## The unofficial Level 3.5

Practitioner commentary (not the article) observes engineers plateau around 2x at Level 3 because running several agents in parallel — an estimated 5–10x — burns out human supervisory bandwidth first. The bottleneck shifts from coding speed to review and orchestration capacity, which prefigures the article's own emphasis on predefined workflows and output templates.

**Covers:** the four-level framework — Level 1 baseline, Level 2 pair programmer and its majority status, Level 3 plain-English-to-code/tests/docs mechanism and LLM evolution driver, Level 4 end-to-end delivery with 20x leverage and experimental status, and third-party Level 3.5 commentary.
