# Connections

- [[agent_memory/MementoTeachingLlmsToManageTheirOwnContext/summary|Memento: Teaching LLMs to Manage Their Own Context]] — shares-technique / complementary: Memento trains agents to compress reasoning into dense summaries for KV-cache reduction and treats "compression that preserves performance" as the goal; this paper measures the *interaction cost* of exactly that kind of compression that a completion-only evaluation of Memento-style methods would miss.
- [[agent_memory/ContextualAgenticMemoryIsAMemo/summary|Contextual Agentic Memory Is A Memo]] — same-problem-different-method: argues all agent "memory" is context engineering with a proven compositional-complexity gap and worse cross-session attack surfaces; this paper supplies an empirical, causal measurement protocol for exactly the kind of hidden cost that critique argues context-engineering approaches incur.
- [[agent_memory/AnatomyOfAgenticMemory/summary|Anatomy of Agentic Memory]] — builds-on: independently critiques memory/compression benchmarks for being underscaled and for metrics (F1/BLEU) that misalign with semantic correctness and hide a maintenance "agency tax"; this paper is a concrete instance of that exact blind spot, showing task completion specifically (not just F1) fails to expose compression's true cost.
- [[agent_harness/BuildingEffectiveAICodingAgents|Building Effective AI Coding Agents]] — applies-in-practice: describes a production coding-agent harness with "adaptive context compaction" as a real deployed feature; this paper's protocol (retrieval vs. execution tool-call decomposition, oracle restoration) is a directly applicable evaluation method for auditing whether that compaction feature is actually cheap to run.
- [[agent_memory/OcrMemory/summary|OCR Memory]] — same-problem-different-method: achieves ~10x context compression via visual-image storage with a "faithfulness" retrieval metric on long-horizon benchmarks; contrasts with this paper's finding that *content validity* (not clever encoding) is what determines whether a compressed memory representation is behaviorally cheap to use.
