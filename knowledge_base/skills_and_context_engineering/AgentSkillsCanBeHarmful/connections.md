# Connections

- [[skills_and_context_engineering/SokAgenticSkillsBeyondToolUseInLlmAgents|SoK: Agentic Skills -- Beyond Tool Use in LLM Agents]] — Shares the core object of study (SKILL.md-style reusable procedural modules) and its own evidence that self-generated/unverified skills degrade performance, but this paper goes further by empirically confirming and taxonomizing 307 concrete skill-induced failures via contrastive differential testing rather than proposing lifecycle/design-pattern theory.
- [[skills_and_context_engineering/AutomatingSkillAcquisitionThroughLargeScaleMining|Automating Skill Acquisition through Large-Scale Mining of Open-Source Agentic Repositories]] — Same-problem-different-angle: that paper finds 26.1% of community-mined skills contain security vulnerabilities and proposes a static/behavioral verification pipeline, while this paper shows harm also comes from functionally "clean" skills that corrupt task implementation or bloat context/procedure even without malicious intent.
- [[skills_and_context_engineering/SkillRetrievalAugmentation/summary|Skill Retrieval Augmentation for Agentic AI]] — Contradicts the implicit "more/better skill retrieval is always good" assumption from a different angle: SRA-Bench shows the bottleneck is agents failing to be need-aware/relevance-aware about *whether* to load a retrieved skill, which is the same root failure mode as this paper's Applicability Mismatch and Context-Bloat categories but studied at the retrieval-selection stage rather than post-hoc via contrastive auditing.
- [[agent_harness/HarnessUpdatingNotHarnessBenefit/summary|Harness Updating Is Not Harness Benefit: Disentangling Evolution Capabilities in Self-Evolving LLM Agents]] — Builds a complementary lens on the same underlying phenomenon: that paper shows harness/skill additions have non-monotonic benefit across model tiers (weak models can't even follow them, strong models barely need them), which offers a plausible explanatory mechanism for why this paper's skill-induced functional failures and efficiency regressions occur even when the loaded skill is topically correct.
