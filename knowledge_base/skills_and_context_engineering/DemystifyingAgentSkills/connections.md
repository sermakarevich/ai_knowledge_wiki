# Connections

- [[research/AgentSkillsCanBeHarmful/summary|Agent Skills Can Be Harmful]] — near-sibling methodology: both papers use a contrastive/differential design (matched target vs. reference runs) to attribute agent failures specifically to loaded skills rather than base-model limits, and both build human/LLM-validated failure taxonomies (this paper's SC3 invocation/misapplication failures parallel their "Task-Implementation Fault" and "Applicability Mismatch" categories). Complementary rather than duplicative: this paper measures skill vs. workflow-memory representation effects and retrieval-precision collapse, while AgentSkillsCanBeHarmful focuses on confirming and root-causing specific skill-induced regressions (functional failures and >2x efficiency regressions) via their SkillTriage tool.
- [[research/MSCEMemorySkillCoEvolution/summary|From Memory to Skills: Evidence-Grounded Co-Evolution Governance]] — shares the memory-to-skill distinction at the heart of this paper's RQ1 (does distilling raw trajectories into a standardized artifact matter beyond raw memory injection). MSCE's evidence-gated "skill crystallization" (only promote a policy to a callable skill if it shows net-positive, evidence-backed gain) is a candidate mechanism for exactly the SC3 misapplication failures this paper documents growing to 10% of skill-arm cases — MSCE's governance layer is one plausible fix.
- [[research/BeyondDomainsWebSkills/summary|Beyond Domains: Reusing Web Skills via Transferable Interaction Patterns]] — addresses the same underlying problem (skill retrieval/matching degrading as libraries and structural variation grow) but in the web-browsing domain via layout-conditioned retrieval (accessibility-tree tree-edit-distance) rather than terminal/coding tasks; a useful cross-domain comparison for whether the retrieval-precision-collapse finding here (driven by semantically similar distractors) generalizes to a domain where structural, not just semantic, similarity is the retrieval signal.
- [[research_topics/skills_and_context_engineering/SkillRetrievalAugmentation/summary|Skill Retrieval Augmentation]] — formalizes Skill Retrieval Augmentation (SRA) over a 26K-skill corpus and independently identifies need-aware/relevance-aware loading (not raw retrieval quality) as the bottleneck — directly consistent with this paper's finding that exact ground-truth retrieval and downstream success are only loosely coupled (retrieval precision collapses to 3.3% while task success barely moves).
- [[research_topics/skills_and_context_engineering/SokAgenticSkillsBeyondToolUseInLlmAgents|SoK: Agentic Skills Beyond Tool Use]] — a systematization-of-knowledge covering the lifecycle, design patterns, taxonomy, and security threat model for agentic skills generally; this paper's empirical, human-validated 12-mode failure taxonomy is a concrete instance of the failure/lifecycle categories that SoK-level work tries to systematize.
