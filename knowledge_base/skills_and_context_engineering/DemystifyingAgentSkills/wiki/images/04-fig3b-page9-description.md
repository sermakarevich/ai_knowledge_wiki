**Reported trends (prose, approximate values).**

Concrete sub‑modes drop sharply under skills, e.g. environment/infrastructure failure ~5% → ~2% → ~0.2%, output‑format/schema mismatch ~7% → ~3%, background‑service‑lifecycle ~3% → ~0.8%. Interpretation: setup, formatting, and service‑management problems are "highly skillable" once a reliable procedure is known.
- *Reasoning/verification limits:* some modes do **not** improve — algorithmic logic error stays ~8–11% across all arms, and static‑verification‑without‑runtime stays ~12%. Interpretation: skills do not auto‑repair a wrong algorithm or enforce oracle‑aligned checking; they reduce operational mistakes, not deep reasoning errors.
- *New skill‑specific failure:* "skill guidance misapplied or ignored" appears only in the skill arm (~10% vs ~0.5–1% in others) — not because the skill is absent, but because the agent applies it mechanically, misses a condition, or carries stale assumptions.
- *Workflow‑memory‑specific failure:* timeout/budget exhaustion is elevated in the workflow arm (~11%) versus ~2–4% in the others — the full trace is procedural "residue" that overloads the agent.
- *Side comparison:* two lightweight baselines (a short instruction‑derived plan ~48% success; a workflow‑derived test‑first template ~59%) sit below Workflow Memory (~62%) and well below Skill injection (~79%).

**Takeaway.** Skills buy robustness on the *operational* layer (setup, I/O formats, service handling) by compressing traces into a clean procedure, but they (a) do not fix tasks that require reformulation or runtime verification, and (b) create a new *invocation/applicability* failure mode where the agent must judge when/how to follow the skill. By contrast, raw workflow memory's penalty is process overload, not misapplication. The overall conclusion is that a "failed skill run" is not evidence of bad skill content; skill utility depends on the surrounding pipeline — distillation to the right abstraction level, retrieval into a compatible context, and online adaptation — which motivates the paper's follow‑on cross‑framework and retrieval studies.
