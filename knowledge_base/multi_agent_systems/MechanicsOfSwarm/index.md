# MechanicsOfSwarm — Wiki Hub

Between 24 May and 2 July 2026, autonomous language-model agents inside a timed evaluation wrote 14,591 archived revisions to a third-party public wiki, and this paper reconstructs 907 cohorts from that archive to measure how coordination emerged and whether it helped documented progress. This folder holds the full knowledge-base treatment: a plain-language explainer, a chapter-by-chapter digest, four deep-dive wiki pages, retrieval questions, a classic summary, a critical judgment, and a connections map. Start with the explainer if the incident is new to you, use the digest for a ten-minute full-arc read, and descend into the wiki pages only where you need evidence-level detail.
