# Connections

- [[Reflexion/summary|Reflexion]] — Closest sibling: both use a frozen LLM's own verbal self-critique to improve behavior with no fine-tuning, but Reflexion stores critiques across trials in a persistent episodic memory keyed by task reward, while Self-Refine loops critique-and-rewrite within a single output; Self-Refine's Math Reasoning failure (model can't spot its own errors without an oracle signal) mirrors Reflexion's own reliance on an external evaluator/reward signal to know when a trial failed at all — both papers need some ground truth outside the self-critique loop to work reliably.
- [[CritiqueOfAgentModel/summary|Critique of Agent Model]] — Direct tension at the architecture level: this paper argues genuine agency requires a persistent identity and self-directed learning loop, distinct from scripted execution; Self-Refine is squarely an "agentic" (externally scaffolded, prompt-driven) loop in that framework's own terms — its critique-and-refine cycle is a fixed three-step script per task instance, not an evolving, self-directed process, which is exactly the kind of capability the Critique paper says looks like agency but isn't.
- [[SelfHarnessHarnessesThatImproveThemselves/summary|Self-Harness: Harnesses That Improve Themselves]] — Same self-critique-then-fix pattern applied one level up: Self-Refine improves a single output via generate→feedback→refine, while Self-Harness improves the harness (prompts/tool config) that produces many outputs via mine-weaknesses→propose→validate; both papers show a fixed LLM can meaningfully improve something about its own process without external help or retraining, but Self-Harness explicitly validates each change before keeping it, a safeguard Self-Refine lacks (it just keeps looping or stops on a self-declared "looks good" signal).
- [[ReAct/summary|ReAct]] — Complementary rather than competing: ReAct grounds reasoning by interleaving thoughts with real environment actions/observations, which is one way to solve Self-Refine's core weakness (a model that can't verify its own math or facts in isolation) — pairing Self-Refine's critique-and-rewrite loop with ReAct-style tool calls for the feedback step would give the loop the external grounding Self-Refine itself has to bolt on as an "oracle correctness signal" for math.
