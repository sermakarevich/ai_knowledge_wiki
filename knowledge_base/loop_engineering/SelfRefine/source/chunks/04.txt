Recall that the Base LLM requires a generation prompt p g ​ e ​ n p_{gen} with input-output pairs ⟨ x i , y i ⟩ \langle x_{i},y_{i}\rangle , the feedback module requires a feedback prompt p f ​ b p_{fb} with input-output-feedback triples ⟨ x i , y i , f ​ b i ⟩ \langle x_{i},y_{i},fb_{i}\rangle , and the refinement module ( refine ) requires a refinement prompt p r ​ e ​ f ​ i ​ n ​ e p_{refine} with input-output-feedback-refined quadruples ⟨ x i , y i , f ​ b i , y i + 1 ⟩ \langle x_{i},y_{i},fb_{i},y_{i+1}\rangle .
•
Sentiment Reversal We create positive and negative variants of a single review from the training set and manually write a description for converting the negative variant to positive and vice versa. For each variant, the authors generate a response and create a feedback f ​ b i fb_{i} based on the conversion description.
•
Dialogue Response Generation
We sample six examples as ⟨ x i , y i ⟩ \langle x_{i},y_{i}\rangle for the few-shot prompt for the Base LLM. For each output y i y_{i} , the authors create a response, evaluate it based on a rubric to generate f ​ b i fb_{i} , and produce an improved version y i + 1 y_{i+1} .
•
Acronym Generation We provide the Base LLM with a total of 15 (title, acronym) examples.
Then, for one title ( x i x_{i} ) we generate an acronym ( y i y_{i} ) using ChatGPT.
The authors then score the acronyms based on a 5-point rubric to create the corresponding f ​ b i fb_{i} , and write improved versions of the acronym to create y i + 1 y_{i+1} .
3 such examples are used for refine and feedback .
•
Code Optimization We use the slow ( x i x_{i} ) and fast ( y i y_{i} ) versions of programs released by Madaan et al. (2023) for Base LLM.
We use their provided explanations ( Madaan et al., 2023 ) for feedback and refine .
•
Math Reasoning The prompts for the Base LLM are sourced from PaL  ( Gao et al., 2022 ) as ⟨ x i , y i ⟩ \langle x_{i},y_{i}\rangle .
We select two examples from the training set on which Codex fails when prompted with PaL-styled prompts, and manually write the correct solution ( y i + 1 y_{i+1} ) and reasoning ( f ​ b i fb_{i} ) for refine and feedback .
•
Constrained Generation We provide ten examples to the Base LLM as ⟨ x i , y i ⟩ \langle x_{i},y_{i}\rangle .
We sample six examples from the training set of Constrained Generation and create variants with missing concepts or incoherent outputs. The missing concepts and the reason for incoherence form f ​ b fb .
