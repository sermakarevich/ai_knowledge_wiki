# Connections

- [[../MSCEMemorySkillCoEvolution/summary|From Memory to Skills: Evidence-Grounded Co-Evolution Governance]] — Directly extends Reflexion's verbal-reflection idea: MSCE's "reflection-weighted value-backfilling" blends sparse terminal rewards with dense self-reflections (Reflexion's core mechanism), then goes further by crystallizing only evidence-backed reflections into reusable skills rather than replaying raw notes every trial — a natural answer to Reflexion's own bounded-memory (1-3 items) limitation.
- [[../SelfHarnessHarnessesThatImproveThemselves/summary|Self-Harness: Harnesses That Improve Themselves]] — Same "improve via language, not weights" philosophy applied one level up: instead of an agent reflecting on its own task attempts, Self-Harness has the agent mine its own failure patterns to rewrite its operating instructions (harness), with a validation gate before keeping any change. Reflexion's "no formal success guarantee" caveat maps directly onto Self-Harness's proposal-validation stage.
- [[../MemoryInTheAgeOfAIAgents/summary|Memory in the Age of AI Agents: A Survey]] — Provides the taxonomy Reflexion's episodic memory sits inside: Reflexion's bounded reflection buffer is a concrete instance of the survey's "experiential, case-based, token-level" memory category, useful for placing Reflexion's specific design choices (small sliding window, verbal not vector) against the broader design space.
- [[../CanLLMAgentsInferWorldModels/summary|Can LLM Agents Infer World Models? Evidence from Agentic Automata Learning]] — A useful counterpoint: this paper shows LLM agents struggle to systematically explore and track hypotheses in a controlled trial-and-error setting (DFA inference), which is close kin to Reflexion's own WebShop failure — both suggest that verbal self-correction helps with locally-correctable mistakes but not with tasks demanding genuinely systematic or diverse exploration.
