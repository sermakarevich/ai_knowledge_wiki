# Human-AI Experience in Integrated Development Environments: A Systematic Literature Review

This folder distils a PRISMA-guided review of 90 empirical studies (2022–2024) on AI assistance inside IDEs. The core takeaway: assistants speed up routine coding but add verification overhead, trust and reliance vary by expertise and task stakes, and generated code carries correctness and security risks.
