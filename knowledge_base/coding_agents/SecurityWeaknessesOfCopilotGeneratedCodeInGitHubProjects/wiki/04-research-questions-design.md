# Research Questions and Study Design
**In one sentence:** RQ3 asks whether Copilot Chat can fix security weaknesses in Copilot-generated code via a collect → analyze → fix-in-Chat → re-analyze loop, and the study collects Python/JavaScript Copilot-labeled code from GitHub using {by, use, with} + tool-name keywords, deduplicated to 3,589 results and manually filtered with high agreement (Kappa 0.84).
## Key points
- RQ3 is: "Can Copilot Chat help fix the security weaknesses found in the code generated by Copilot?" because most weaknesses in RQ1/RQ2 come from Copilot.
- The RQ3 method is a loop: collect generated code → analyze for weaknesses → check for fixes in Copilot Chat → re-analyze to check if the fix is correct.
- Rationale given: "The purpose of Copilot Chat is to assist developers by answering questions about their code or providing fixes for issues identified in the code," integrated with Copilot and claimed to assist in fixing security weaknesses.
- Search used GitHub REST API with keyword combinations {by, use, with} + {GitHub Copilot, CodeWhisperer, Codeium}, restricted to Python and JavaScript, retaining Code-label files and Repo-label projects.
- After removing duplicates there were 3,589 search results: 3,141 from the Code label and 445 from the Repository label (raw Table 1 total 9,927 before dedup).
- Filtering kept Repository-label projects fully generated by Copilot per description/README (Criterion 1) and Code-label files with comments showing Copilot generation (Criterion 2), and excluded simple practice-problem files such as LeetCode/BOJ-number exercises (Exclusion 1).
- Two authors independently filtered all data over two weeks with Cohen's Kappa 0.84 (>0.8), indicating high agreement.
- Python and JavaScript were chosen as dynamically typed languages needing no compilation database, the two most popular languages with developers and most frequently used with Copilot.

## RQ3 goal and rationale
**Covers:** RQ3 statement and rationale (chunk lines 3–14)

> "RQ3. Can Copilot Chat help fix the security weaknesses found in the code generated by Copilot?"

- Purpose stated: "Copilot Chat is integrated with Copilot to form a powerful AI assistant that can help developers build at their speed of thought in the natural language of their choice [23]. It is claimed that Copilot Chat can assist in fixing security weaknesses."
- Motivation: "most of the security weaknesses in RQ1 and RQ2 come from Copilot."
- Approach: "utilize Copilot Chat in the loop by collect generated code → analyze the code for security weaknesses → check for fixes in Copilot Chat → re-analyze the code to check if the fix is correct."

## Data source and tool choice
**Covers:** Section 3.2 intro (chunk lines 19–34)

- GitHub chosen as "the world's largest code hosting platform" with millions of public repositories, covering multiple languages and project types.
- Copilot is the main subject: "a well-known commercial instance of an AI pair programming tool," popular since 2021 launch, "only second to ChatGPT" among AI assistance tools developers use [53].
- Also attempted CodeWhisperer and Codeium (both general-purpose AI-driven generators) for generalizability; excluded specialized tools such as AlphaCode as it "focuses on solving complex coding tasks rather than everyday code generation."

## Code snippet collection
**Covers:** Section 3.2.1 (chunk lines 36–71)

- Step 1 used GitHub REST API; pilot search showed bare "GitHub Copilot" / "CodeWhisperer" terms returned snippets merely mentioning the tool, so they restricted to {by, use, with} + {GitHub Copilot, CodeWhisperer, Codeium}.
- Limited to Python and JavaScript because both are dynamically typed ("full analysis can be conducted without the need for compilation"), are "currently the two most popular programming languages used by developers [28], and the most frequently used with GitHub Copilot [84]."
- Retained Code-filter results (file names, paths, repo forks/stars) and Repo-filter results (project name, path, description, forks/stars) where README/descriptions declared Copilot-generated code.
- "The same search result may contain multiple keywords, meaning there are duplicate projects in the collected data. After removing duplications, we ended up with 3,589 search results, of which 3,141 were from the Code label and 445 from the Repository label."

## Filtering code snippets
**Covers:** Section 3.2.2 (chunk lines 87–116)

- Step 2 filtered by project documentation, code comments, and metadata to confirm generation by Copilot and other tools, and manually excluded simple programming-practice problems (e.g., "bisection lookup and fast sorting tasks from LeetCode") as "more closely related to correctness than security."
- Terminology: Repository-label results are projects containing code files; Code-label results are individual code files containing Copilot-generated snippets.
- Inclusion Criterion 1: Repository-label projects fully generated by Copilot as declared in project description or README; retained Python and JavaScript files (Figure 4 example).
- Inclusion Criterion 2: Code-label files with comments showing the code was generated by Copilot; kept the entire file (Figure 5 example).
- Exclusion Criterion 1: excluded files solving simple practice problems, "often named BOJ-number" (Figure 6 example).
- "Two authors independently completed this manual filtration process for all the data within a period of two weeks," with "Cohen's Kappa coefficient was 0.84, which was higher than 0.8, indicating a high level of agreement between the two coders."
