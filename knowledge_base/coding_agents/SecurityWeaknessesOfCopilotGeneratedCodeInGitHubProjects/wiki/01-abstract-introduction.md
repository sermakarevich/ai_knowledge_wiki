# Abstract and Introduction: Security Weaknesses of Copilot-Generated Code in GitHub Projects
**In one sentence:** This empirical study analyzes 733 Copilot/CodeWhisperer/Codeium-generated snippets from GitHub projects, finds a high rate of security weaknesses (29.5% Python, 24.2% JavaScript across 43 CWE categories), and shows up to 55.5% can be fixed via Copilot Chat fed with static-analysis warnings.
## Key points
- Analyzed 733 code snippets generated by GitHub Copilot and two other AI tools (CodeWhisperer and Codeium) collected from GitHub projects.
- 29.5% of Python snippets and 24.2% of JavaScript snippets contained security weaknesses.
- Weaknesses span 43 Common Weakness Enumeration (CWE) categories, including CWE-330 (Use of Insufficiently Random Values), CWE-94 (Improper Control of Generation of Code), and CWE-79 (Cross-site Scripting).
- Eight of the 43 CWEs are among the 2023 CWE Top-25, highlighting their severity.
- Feeding Copilot Chat with warning messages from static analysis tools fixed up to 55.5% of the security issues in Copilot-generated code.
- LLM-based tools are trained on billions of public open-source lines of code that include unsafe coding patterns, so generated code may inherit security weaknesses.
- GitHub Copilot's underlying Codex model was pre-trained on untrusted GitHub data known to contain buggy programs, and Snyk reports Copilot may replicate existing weaknesses when the user's codebase already contains them.
- Copilot's algorithms are incentivized to suggest code to be accepted rather than code with other qualities (e.g., readability), and GitHub states users are responsible for ensuring security and quality of their code.

## Introduction: motivation and gap
**Covers:** Section 1 INTRODUCTION start (p. 2–3).

- Code generation tools generate functional code from prompts (text descriptions/comments, code such as function signatures/expressions/variable names, or both), letting developers complete remaining code to save time.
- Early work traces to the 1960s (Waldinger and Lee's program synthesizer PROW for LISP from predicate calculus); meta-programming and later deep learning accelerated the field.
- Recent advance: LLMs (e.g., GPT models, Codex by OpenAI, AlphaCode by DeepMind, CodeWhisperer by Amazon) trained on large code/text corpora.
- Security concern: "These models are trained on billions of public open-source lines of code, which include public code with unsafe coding patterns"; generated code "may also suffer from security weaknesses."
- Copilot-specific risk: "GitHub Copilot may produce some insecure code, as its underlying Codex model is pre-trained on untrusted data from GitHub, which is known to contain buggy programs"; per Snyk, "GitHub Copilot may also replicate existing security weaknesses in code to suggest insecure code when the user's existing codebase contains security weaknesses."
- Vicious-cycle risk stated: vulnerable generated code "may continue to be used to train the model, thus further generating code with vulnerabilities."
- Research gap: prior work focused more on correctness than security; "potential security weaknesses in practical scenarios have not been fully considered"; prior security work mostly used controlled environments rather than open-source development scenarios.
- Responsibility and incentives (verbatim): GitHub Copilot clarifies that "the users of Copilot are responsible for ensuring the security and quality of their code"; "Code generation algorithms of Copilot are incentivized to suggest code to be accepted rather than other code qualities, e.g., easy to read and understand, which has an adverse impact on the code quality generated by Copilot."
- Study choice: empirical study of generated code by GitHub Copilot plus CodeWhisperer and Codeium as available on GitHub; Copilot is the main subject as a commercial AI-programming instance popular since its 2021 launch.
