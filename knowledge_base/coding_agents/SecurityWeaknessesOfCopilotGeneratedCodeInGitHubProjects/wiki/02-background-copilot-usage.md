# Background: Copilot Usage and Related Work
**In one sentence:** This chunk sets up the study's scope — real Copilot/CodeWhisperer/Codeium-generated code collected from GitHub and checked with static analysis tools for all CWE types — and surveys related work showing code generators are functionally effective but their security remains under-examined.
## Key points
- The study collects code generated by Copilot plus CodeWhisperer and Codeium that has actually been used in GitHub projects, explicitly to increase generalizability beyond Copilot alone.
- Collected snippets are analyzed with static analysis tools and classified with Common Weakness Enumeration (CWE) across all CWE types, framed through the lens of the open-source development environment.
- Prior functional evaluations report high effectiveness: Yetistiren et al. report Copilot generates valid code with a 91.5% success rate, while Sobania et al. found no significant difference vs. a Genetic Programming generator and Nguyen and Nadi tested 33 LeetCode problems in four languages.
- Developer-experience studies report Copilot provides a useful starting point but does not necessarily improve task time or success rate, with difficulties understanding, editing, and debugging suggestions (Vaithilingam et al.) and a 20-participant interaction theory (Barke et al.).
- Security-focused prior work reports substantial weakness rates in prompted generations: Pearce et al. found 40% of suggestions across 89 cybersecurity scenarios contained CWE-classified bugs, and Elgedawy et al. compared four models over nine tasks with 61 code outputs.
- Sandoval et al. and Asare et al. compare AI-assisted vs. human code: Sandoval et al. report AI users produced critical security errors at no more than 10% of the control-group rate, while Asare et al. found Copilot differs by vulnerability type but is "not as bad as" human developers.
- This study differentiates itself from Pearce et al. by using developer-written production code from GitHub rather than author-prompted high-risk scenarios, and by using various static analysis tools to examine all CWE types rather than only scenario-targeted CWEs.

## Study scope and claimed findings
The chunk states the GitHub community has shared experiences of using Copilot in open-source projects [12], and the authors include CodeWhisperer and Codeium output "for the purpose of increasing the generalizability of this research."

> "Our findings show that: (1) around 30% of code snippets have security weaknesses; (2) the security weaknesses are diverse and related to 43 different CWEs, in which CWE-330: Use of Insufficiently Random Values, CWE-94: Improper Control of Generation of Code ('Code Injection') and CWE-79: Cross-site Scripting and are the most frequently occurred; and (3) among the 38 CWEs identified, eight CWEs belong to the currently recognized 2023 CWE Top-25. ## 2.1 AI Code Generation Tools
Covers functional/correctness and developer-experience evaluations of IDE-integrated transformer-based generators:

| Study | Setup | Result reported in chunk |
|---|---|---|
| Yetistiren et al. [82] | Effectiveness, correctness, efficiency of Copilot | Valid code with 91.5% success rate; "a promising tool" |

| Nguyen and Nadi [50] | 33 LeetCode problems, queries in four languages; LeetCode tests for correctness/comprehensibility | Copilot suggestions have lower complexity |

## 2.2 Security of Code Generation Techniques and LLMs
Covers security evaluations, human-vs-AI comparisons, and datasets:

| Study | Setup | Result reported in chunk |
|---|---|---|
| Pearce et al. [55] | Prompted Copilot for 89 cybersecurity scenarios; checked known weaknesses | 40% of suggestions in the relevant context contained security bugs (MITRE CWE [46]) |
| Siddiq et al. [67] | Code smells in training set of transformer-based Python model and impact on generated code | Copilot introduces 18 code smells, including non-standard patterns and two security smells ("code patterns that often lead to security defects") |
| Khoury et al. [37] | Security of ChatGPT (LLM chatbot) source code | ChatGPT aware of potential weaknesses but still frequently generated non-robust code |
| Elgedawy et al. [18] | Four code generation models, nine tasks, 61 code outputs | Code from different LLMs exhibited disparate security robustness |
| Sandoval et al. [64] | Security-driven user study | AI-user programming produced critical security errors at no more than 10% of the control group; LLMs do not introduce new security risks |
| Asare et al. [1] | Comparative empirical analysis, security perspective | Copilot performs differently across vulnerability types; not as bad as human developers at introducing vulnerabilities |
| Tony et al. [76] | LLMSecEval dataset | 150 natural-language prompts for evaluating LLM security |
| Siddiq et al. [68] | SecurityEval dataset | 130 Python code samples for testing model weaknesses |
| Natella et al. [49] | Dataset + experimental evaluation | Security of three LLMs: GitHub Copilot, Amazon CodeWhisperer, and CodeBERT |

Differentiation claimed vs. prior work:
- Data source: code snippets from GitHub generated by developers using Copilot in daily production, vs. Pearce et al. where authors generated code from high-risk network-security prompts.
- Coverage: various static analysis tools examining all CWE types extensively, vs. Pearce et al. configuring CodeQL only for scenario-targeted CWEs.
- Intended use: help developers understand common CWEs from real Copilot use in real coding.

## 2.3 How AI Code Generation Tools Work: Copilot as an Example
Tools (Copilot, CodeWhisperer, Codeium) are typically IDE-integrated, giving real-time suggestions from prompts ranging from snippets to complete functions. Copilot's stated actions when scanning the program [10]:
1. Complete existing code from function or variable names.
2. Generate suggestions from inline natural-language comments.
3. Automatically fill repetitive code from existing-code context.
4. Generate test cases.
