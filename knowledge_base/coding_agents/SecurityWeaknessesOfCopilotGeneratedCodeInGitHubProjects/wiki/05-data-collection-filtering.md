# Data Collection, Labeling Agreement, and Filtering

**In one sentence:** Two authors labeled GitHub search results, resolved disagreements by negotiated agreement, and retained 116 Repository-label projects and 335 Code-label files, yielding a 733-file dataset (672 Copilot, 38 CodeWhisperer, 23 Codeium) dominated by small, low-popularity projects.

## Key points
- Labeling disagreements between the two authors were resolved through a negotiated agreement approach [5] during a meeting.
- Manual filtration retained 116 projects under the Repository label and 335 code files under the Code label.
- Repository-label files are treated wholesale as AI-generated because the README states all code was generated by Copilot and other tools.
- Code-label files are known to contain only snippets (possibly a few lines) of AI-generated code, with attribution decided later via warning messages plus code comments (Section 3.3.2).
- Final dataset: 733 distinct code files — 672 from Copilot, 38 from CodeWhisperer, and 23 from Codeium.
- Language split: Python 419 files (190 Repository + 229 Code); JavaScript 314 files (208 Repository + 106 Code).
- Projects with AI-generated code tend to be small and low-popularity, possibly individual/small-team efforts, consistent with Yu et al. [83]; low popularity may correlate with project newness since Copilot itself is recent.
- Notable exception: the project OnmyojiAutoScript received 1,672 stars and 505 forks.

## Repository label vs Code label

- Repository label: "we consider the entire code file as code generated by Copilot and other code generation tools... because it was stated in the README file that it was all generated by Copilot and other code generation tools."
- Code label: "we know that the files contain code snippets, perhaps even just a few lines of code, generated by Copilot and other code generation tools. Instead of identifying the specific AI-generated code in this step, we combine the warning messages from the security analysis and the code comments in the file to determine whether Copilot and other code generation tools generate the code snippet with the security problem (this process is explained further in Section 3.3.2)."
