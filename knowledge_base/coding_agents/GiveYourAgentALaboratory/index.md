# Give your agent a laboratory

Brian Lovin's January 2026 essay argues that vague agent prompts fail for lack of a verifiable loop, not poor wording. The fix is to build the agent a laboratory first — benchmarks, browser screenshots, and design-source access — so it can measure and verify its own work, then distill proven loops into reusable skills.
