# From Restructuring to Stabilization: A Large-Scale Experiment on Iterative Code Readability Refactoring with Large Langu

This folder distils a large-scale experiment (230 Java snippets × 3 variants × 3 prompts × 5 GPT-5.1 iterations) on what happens when an LLM repeatedly refactors its own output. The headline result is a restructuring-then-stabilization dynamic: a heavy first-pass cleanup followed by converging micro-edits that never fully stop. Start with the summary for the takeaway, then use the digest and wiki pages for the numbers.
