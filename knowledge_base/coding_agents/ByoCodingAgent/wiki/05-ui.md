# TUI: program, input, styles, compaction view

**In one sentence:** The `internal/ui` package implements the Bubble Tea terminal UI — a `harness` model with conversation viewport, input box, debug panel, approval modals, banner animation, and stdout helpers for spinner, highlight, and compaction views.

## Key points

- The main TUI is a `harness` struct holding conversation `viewport`, bottom debug `viewport`, `textinput`, and `spinner` models plus window size, state, approval, focus, shine, MCP, and scrollback fields (`internal/ui/program.go:95`).
- Three model states drive interaction — `stateIdle`, `stateRunning`, `stateAwaitingApproval` — declared as a `modelState` enum (`internal/ui/program.go:87`).
- `NewProgram` captures terminal width before stdout redirection, builds the banner, and runs with alt-screen plus full mouse motion (`internal/ui/program.go:194`).
- User input echoes into scrollback with a timestamped turn divider, then dispatches via `AgentRunner` and flips to `stateRunning` with spinner tick (`internal/ui/program.go:426`).
- Approval uses `ApprovalRequest{Prompt, Detail, Reply chan bool}`; a non-empty `Detail` opens a yellow full-screen diff modal with scrollable viewport, `y` approves and everything else denies (`internal/ui/program.go:55`, `internal/ui/program.go:466`).
- The debug panel occupies `debugPanelHeight = 12` rows, toggles with `Tab`, supports list/detail modes with `↑/↓` navigation, `Enter` drill-in, `←/→` pair jumps, and mouse selection (`internal/ui/program.go:28`, `internal/ui/program.go:650`).
- Standalone (non-alt-screen) prompts live in `input.go`: `ReadChatInput() (string, bool)` with `↑↓` history from `~/.bettatech_harness_history`, and `Confirm(prompt string) bool` defaulting Enter/Esc/Ctrl-C to deny (`internal/ui/input.go:119`, `internal/ui/input.go:168`).

## Program model and states

Constructor entry point (`internal/ui/program.go:194`):

```go
func NewProgram(runner AgentRunner, usageFunc UsageFunc) *tea.Program
```

It captures `TermWidth()` before `main.go` redirects stdout into the alt-screen pipe, builds `BannerText(width)`, calls `newHarness(runner, usageFunc, banner)`, and returns `tea.NewProgram(m, tea.WithAltScreen(), tea.WithMouseAllMotion())` (`internal/ui/program.go:194`). `Init()` returns `tea.Batch(textinput.Blink, shineTickCmd())` only when `bannerWidth >= bigBannerMinWidth`, else just `textinput.Blink` (`internal/ui/program.go:207`).

`Update` dispatches on message type (`internal/ui/program.go:251`): `tea.WindowSizeMsg` re-runs `layout()` and re-wraps scrollback (`internal/ui/program.go:253`); `DebugToggleMsg` recomputes layout and resets focus (`internal/ui/program.go:271`); `DebugRefreshMsg` re-renders the panel (`internal/ui/program.go:286`); `MCPStatusMsg` tracks `ProgressBegin/Connecting/Connected/Failed/Done` counters (`internal/ui/program.go:292`); `tea.MouseMsg` left-click maps to `mouseSelect` (`internal/ui/program.go:320`); `tea.KeyMsg` routes to `updateApproval`, `toggleDebugFocus`, `updateDebugFocus`, or `updateInput` (`internal/ui/program.go:331`); `AppendMsg` appends stdout-pipe text to scrollback (`internal/ui/program.go:346`); `agentDoneMsg` returns to idle and prints errors dimmed (`internal/ui/program.go:354`); `ApprovalRequest` stores prompt/detail/reply channel (`internal/ui/program.go:365`); `shineTickMsg` advances the banner animation (`internal/ui/program.go:380`); `spinner.TickMsg` animates only while running or MCP-loading (`internal/ui/program.go:407`).

`View()` renders the approval-with-diff modal first, then the debug-detail modal, else viewport + optional debug box + input area joined vertically (`internal/ui/program.go:942`).

## Input handling and history

The live input path is `updateInput` (`internal/ui/program.go:426`): `Enter` when idle trims the value, writes `renderTurnHeader(width)` plus styled `❯ <text>` into scrollback, clears the box, sets `stateRunning`, and batches `runOnce(text)` with `spinner.Tick` (`internal/ui/program.go:428`). `Ctrl-D/Ctrl-C` quits; `PgUp/PgDn/Home/End` scroll the viewport and update `followBottom` (`internal/ui/program.go:451`). `runOnce` calls `m.runner(context.Background(), text)` and returns `agentDoneMsg` (`internal/ui/program.go:509`).

The legacy standalone input models in `input.go` are used outside alt-screen mode (`internal/ui/input.go:28`):

```go
func ReadChatInput() (string, bool)
```

Built by `newChatInput(width, history)` with prompt `❯ `, unlimited `CharLimit`, and width `max(width-6, 20)` (`internal/ui/input.go:38`). `Update` handles `Enter` (submit + `tea.Quit`), `Ctrl-D` on empty (quit), `Ctrl-C` (clear line), `Up/Down` history navigation preserving `bufferText` (`internal/ui/input.go:55`). `View` renders a cyan rounded box plus `enter: send · ↑↓: history · ctrl-d: exit` hint (`internal/ui/input.go:107`). History persists one line per entry in `~/.bettatech_harness_history` via `historyPath`, `loadHistory`, `appendHistory` (`internal/ui/input.go:178`, `internal/ui/input.go:186`, `internal/ui/input.go:207`).

The standalone confirm (`internal/ui/input.go:141`):

```go
func Confirm(prompt string) bool
```

`y/Y` approves; `n/N/esc/ctrl-c/ctrl-d/enter` denies, so Enter defaults to deny (`internal/ui/input.go:148`). View renders a yellow `?` mark plus `(y/n)` hint (`internal/ui/input.go:162`).

## Approval flow

Request type (`internal/ui/program.go:55`):

```go
type ApprovalRequest struct {
	Prompt string
	Detail string
	Reply  chan bool
}
```

Inline (no `Detail`) renders a yellow `? <prompt> (y/n)` box above the input via `inputArea()` (`internal/ui/program.go:1081`). With `Detail` (e.g. `write_file` unified diff), `Update` resizes `debugView` to modal size and fills it with `HighlightPayload(m.approvalDetail, m.debugView.Width)` (`internal/ui/program.go:370`), and `View` switches to `viewApprovalModal()` — yellow rounded border, title + separator + diff viewport, centered with `y: approve · n / esc: deny · pgup/pgdn / ↑↓: scroll` hint (`internal/ui/program.go:965`).

Key handler `updateApproval` (`internal/ui/program.go:466`): scroll keys (`PgUp/PgDn/Home/End/Up/Down`) go to the modal viewport when `Detail` is set; `y/Y` resolves `true`; `n/N/esc/ctrl+c/ctrl+d/enter` resolves `false`; anything else is ignored. The verdict (`approved`/`denied`) echoes dimmed into scrollback as `↳ <verdict>`, the reply channel is signaled once, and `layout()` reverts from modal to panel split (`internal/ui/program.go:487`).

## Debug panel and modals

The bottom panel is `debugView`, a second viewport of height `debugPanelHeight-2` shown only when `debug.Enabled()` (`internal/ui/program.go:161`, `internal/ui/program.go:534`). `layout()` shrinks the conversation viewport by `inputHeight (5) + debugH` and, in any modal state (`inModal`: debug-detail or approval-with-diff), resizes `debugView` to the modal body instead (`internal/ui/program.go:520`, `internal/ui/program.go:547`). `modalSize()` clamps to `width-4`/`height-4` within `[30, 140]` wide and `[10, 50]` tall (`internal/ui/program.go:560`).

Modes (`internal/ui/program.go:144`):

```go
const (
	debugList   debugMode = iota
	debugDetail
)
```

`refreshDebugContent` dispatches to `renderDebugList` or `renderDebugDetail` (`internal/ui/program.go:586`). List mode formats each event via `formatDebugEvent` — `#<id> <timestamp> <•?> <source> <msg>` with `↩ #<id>` correlation suffix, cyan provider / green tool / yellow compact / purple `tool/*` sources, red errors, amber warnings — and centers the selection when focused (`internal/ui/program.go:594`, `internal/ui/program.go:805`). Detail mode shows `HighlightPayload(body, width)` for the selected event's payload (`internal/ui/program.go:625`).

Focus: `Tab` calls `toggleDebugFocus`, blurring/focusing input, seeding selection to the latest event, and resetting to list mode (`internal/ui/program.go:650`). `updateDebugFocus` owns `Ctrl-D/Ctrl-C` quit, `Esc` back-out, `Enter` drill-in, `Up/Down/Home/End` selection via `moveSelection`, `Left/Right` request↔response pair jumps via `debug.Pair`, and forwards the rest to the viewport (`internal/ui/program.go:674`). `mouseSelect` maps click Y to a panel row accounting for `viewport.Height` and `YOffset` (`internal/ui/program.go:779`).

`viewDebugModal` renders a cyan rounded modal with `#<id> <time> <source> <msg>` title plus optional `→ response`/`← request` pair hint, vertically centered (`internal/ui/program.go:997`).

## Banner and shine animation

Wide banner needs 75 columns, gated at 78 (`internal/ui/banner.go:13`):

```go
const (
	bigBannerMinWidth = 78
	BigBannerWidth    = 75
)
```

`BannerText(width int) string` returns the bold-cyan ASCII wordmark plus two dimmed taglines when wide, else a one-line `BETTATECH · build your own coding agent` fallback; width `0` defaults to wide (`internal/ui/banner.go:33`). `PrintBanner` prints `BannerText(TermWidth())` (`internal/ui/banner.go:29`). `TermWidth` reads stdout size via `term.GetSize`, returning `0` when not a TTY (`internal/ui/banner.go:147`).

Animation (`internal/ui/banner.go:60`):

```go
func AnimatedBanner(width, shineCol int) string
```

Each block cell gets a 256-color foreground from `shineColor256(col, row, shineCol)`; `-1` returns the settled base color (`internal/ui/banner.go:128`). The gradient `shineGradient` runs white `231` down to base `39` over ~10 steps with a diagonal slope (`col + row`) and half-rate comet trail behind the peak (`internal/ui/banner.go:106`). Timing is `shineTotalTicks = 60` frames at `shineFrameMs = 40` ms (~2.4 s) with `easeInOutCubic` easing and `shineEdgePad = 15` overshoot, driven by `shineTickCmd`/`shineTickMsg` and spliced into scrollback via `replaceBanner` preserving post-banner content (`internal/ui/program.go:221`, `internal/ui/program.go:228`, `internal/ui/program.go:868`).

## Styles, highlight, spinner, compaction view

Base ANSI vocabulary (`internal/ui/styles.go:8`):

```go
const (
	BoldCyan = "\033[1;36m"
	Dim      = "\033[2m"
	Yellow   = "\033[33m"
	Reset    = "\033[0m"
)
```

Helpers `Dimmed(s)` and `Cyan(s)` wrap with `Dim`/`BoldCyan` plus `Reset` (`internal/ui/styles.go:16`). Lipgloss styles built on top: cyan `❯` input prompt, bold prompt echo, dim turn dividers, normal/focused debug boxes, selected-line background (`internal/ui/program.go:847`, `internal/ui/input.go:16`).

Syntax highlight (`internal/ui/highlight.go:20`):

```go
func HighlightPayload(content string, width int) string
```

`detectLanguage` peeks at the first non-whitespace byte: `{`/`[` selects `json`, `--- ` prefix selects `diff`, else no highlighting (`internal/ui/highlight.go:40`). Highlighting uses Chroma `quick.Highlight` with formatter `terminal256` and style `monokai` (`internal/ui/highlight.go:36`), then ANSI-aware wraps to `width` via Lipgloss when `width > 0` (`internal/ui/highlight.go:20`).

Spinner (`internal/ui/spinner.go:11`): braille `spinnerFrames` on an 80 ms ticker printing `\r<BoldCyan><frame><Reset> <Dim><label><Reset>`, cleared with `\r\033[K` on `Stop` (`internal/ui/spinner.go:26`). `SuppressSpinner` disables it when the TUI status bar owns the indicator (`internal/ui/spinner.go:17`). `StartSpinner` no-ops when suppressed or when stdout is not a terminal (`internal/ui/spinner.go:26`).

Compaction view (`internal/ui/compaction.go:11`):

```go
func PrintCompaction(before, after []api.Message)
```

Prints dimmed `─── compaction ───` / `─── after ───` / `──────────────` separators with `BEFORE (N messages)` and `AFTER (N messages)` transcripts rendered by `api.RenderTranscript` (`internal/ui/compaction.go:11`).

Status lines in `inputArea()` (`internal/ui/program.go:1076`): running shows spinner + `thinking...` plus `activeSubagentSummary()` (e.g. `· research ×2`); MCP-loading shows `connecting MCP: <server> (i/N)`; idle shows `usageStatus()` (`1,234 in · 567 out · cache a/b · ~$0.1234`) or empty (`internal/ui/program.go:1060`, `internal/ui/program.go:1126`, `internal/ui/program.go:1165`).
