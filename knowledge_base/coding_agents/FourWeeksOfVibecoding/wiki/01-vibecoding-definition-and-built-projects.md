# Vibecoding Is Not Coding. It Is the Wrong Word.

**In one sentence:** Vibecoding is not writing code but specifying vision, problem understanding, and exact desired behaviour in detail for AI coding tools to execute — proven by a complete non-coder shipping four live projects in four weeks.

## Key points

- On February 12, 2026 the author could not set up a GitHub repo, had never used a terminal to push code or written a commit message; by March 12 he had 197 commits across multiple live projects.
- Prior background was a decade building coliving companies, advising 70+ operators across 14 countries, and running a 36,000-subscriber newsletter — with zero shipped lines of code.
- Definition: "You do not write code. You write the details of how you want things to be done and what exactly you want them to do. The AI coding tools just execute."
- The author does not know JavaScript, TypeScript, Prisma, or why Next.js has an "App Router" — but knows the domain: listing fields, admin permissions, discovery-to-booking journeys, SEO architecture.
- BookMyColiving.com: two-sided marketplace with 3 user roles (tenant, operator, admin), moderation workflows, messaging, reviews, lead management, CSV exports, 2,500+ SEO pages; built on Next.js, TypeScript, Prisma, PostgreSQL, deployed on Vercel.
- EverythingColiving.com rebuild: from 170+ pages to a planned 300+ pages, plus 15 interactive operator tools, a vendor directory, an operator directory, a markets section, and a free templates library.
- JumboTiger: a complete PRD written as a Claude Code execution document (architecture, module deep dives, design system, technical specs, content strategy), precise enough to build without a single clarifying question.
- Process: product requirements spoken into a voice memo app (while walking/driving/between calls), transcribed and structured by AI into a specification, then fed to Claude Code — a detailed prompt becomes a live feature within hours instead of a Jira ticket sitting in backlog for weeks.

## Background: zero to 197 commits in one month

The author states: "I didn't know how to set up a GitHub repo four weeks ago" and "I am not exaggerating. On February 12, 2026, a client and a dear friend forced me to take a Claude Code plan, and my wife set it up for me because I genuinely did not know how."

One month later (March 12): "I have 197 commits across multiple live projects. And I have shipped more product in these four weeks than most funded startups ship in a quarter."

**Covers:** article intro / background section

## Vibecoding is the wrong word

The author was "intimidated by the term for months" because "'Vibecoding' sounds like something developers do when they are in a flow state. It sounds technical. It sounds like you need to understand syntax, languages, and frameworks." His answer: "You don't."

Verbatim definition: "Vibecoding, at least the way I do it, is this: if you have a vision, if you know what you need to build, if you understand the problem deeply enough, you can just get it done."

And on skills: "I do not know JavaScript. I do not know TypeScript. I do not know what Prisma is or why Next.js has an 'App Router.' But I know what a coliving operator needs from a marketplace. I know what SEO architecture looks like for a B2B platform. I know the exact fields a property listing needs, the permissions an admin panel requires, and the user journey from discovery to booking."

## The process: speaking products into existence

Verbatim: "I recorded most of my product requirements by speaking into my voice memo app." The flow: think through the user flow, data model, edge cases, and dislikes of existing solutions while walking, driving, or between calls → speak it out → AI transcribes → structured into a specification → fed to Claude Code for execution.

Verbatim on the skill shift: "Writing PRDs is one of the most significant tasks for product managers. I can now speak in PRD. I can articulate what I want verbally, convert it into structured requirements using AI, and have those requirements executed, sometimes within the same day."

Verbatim on the deliverable change: "The deliverable has changed. It used to be a Jira ticket that sat in a backlog for weeks. Now it is a detailed prompt that becomes a live feature within hours."
