# My LLM coding workflow going into 2026 | AddyOsmani.com

Addy Osmani lays out a practical, human-in-the-loop playbook for coding with LLMs: plan in a spec before generating code, build in small tested steps, and verify everything. The throughline is AI-augmented rather than AI-automated engineering, with the human as the accountable senior and director of the show.
