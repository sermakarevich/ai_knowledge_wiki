# awesome full duplex speech-to-speech

This folder captures a curated guide to full-duplex speech-to-speech conversational models that listen and speak simultaneously instead of taking rigid turns. It maps models, audio representations, datasets, benchmarks, challenges, and commercial products, anchored by Moshi, SyncLLM, GPT-4o Realtime, and Gemini Live. The captured state is an early skeleton (v0.1.0) with body tables as placeholders, so treat it as an orientation map rather than a build guide.
