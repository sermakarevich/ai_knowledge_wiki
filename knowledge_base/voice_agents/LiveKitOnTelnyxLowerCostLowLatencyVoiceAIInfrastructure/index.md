# LiveKit on Telnyx: Lower Cost, Low Latency Voice AI Infrastructure

LiveKit on Telnyx is a fully hosted platform that runs LiveKit voice agents on Telnyx-owned GPUs and carrier infrastructure. It promises roughly 50% savings over LiveKit Cloud, 200ms round-trip latency via colocated inference, and native telephony features (HD voice, transfers, verified caller ID, recording).
