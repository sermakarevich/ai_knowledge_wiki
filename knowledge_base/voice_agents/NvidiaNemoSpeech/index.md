# NVIDIA-NeMo/Speech

NVIDIA-NeMo/Speech (v3.0.0) is a PyTorch toolkit for creating, customizing, and deploying ASR, TTS, and Speech-LLM models from shared code and pre-trained checkpoints. The folder covers the reproducible stack (Python 3.13, pinned PyTorch/CUDA), three install paths, and the repo-root guardrails.
