# FreedomIntelligence/LoopSpeech

LoopSpeech introduces Self-Listening, a playback-grounded approach that feeds already-played model speech back into the listening pathway so full-duplex models recover consistently after interruptions. The repo is Preprint status with code, models, data, and paper link still pending, reporting 73.0% anchoring accuracy on AnchorSpeech-test.
