## Problem & Motivation

Open-source projects with heavy compute needs face the practical problem that GPUs and model API access cost real money, and volunteer-driven development alone cannot reliably cover them. The motivation behind the Sponsor section is therefore straightforward and transparent: publicly credit the cloud provider footing part of that bill while giving prospective users and contributors a concrete path to the same infrastructure. By pairing gratitude with a functional invitation link and a concise description of what the sponsor offers, the section converts a funding necessity into useful onboarding information, so readers who want to build or run CyberVerse themselves know where provisionable compute and model access can be found.

4. **Referral-linked onboarding loop:** the invitation URL with its embedded referral code turns a thank-you note into a measurable acquisition channel, aligning the sponsor's interest in signups with the project's interest in funded infrastructure.
