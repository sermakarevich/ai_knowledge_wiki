# Sponsor — In Plain Language
## What is this about?

This page explains the sponsor behind CyberVerse in plain words.

CyberVerse is a free, open-source toolkit for building talking digital
humans — voice-first AI agents that can listen, speak, remember who you
are, look things up, use tools, and optionally appear on screen as an
animated avatar.

Running that kind of project takes serious computer power, especially
graphics processors (GPUs) for AI models and video.

So the CyberVerse team publicly thanks its sponsor: Compshare (优云智算).

Compshare is described as the AI cloud platform from UCloud, a cloud
company. It sponsored CyberVerse by providing two things: rentable GPU
computing power and access to AI model services through its APIs.

In short: a cloud company lends the project the heavy computers and
model connections it needs, and the project says thank you with a logo
and an invitation link.

## Why does it matter?

Think of building a digital human like running a small TV studio plus a
research lab at the same time.

You need microphones, voices, brains, memories — and all of that runs on
expensive, power-hungry chips called GPUs.

For an open-source project, buying all those chips outright is usually
out of the question. Rental changes the math:

- You only pay for the time you actually compute.
- You can get a machine quickly instead of waiting weeks for hardware.
- You can try a bigger or faster chip for one experiment, then give it
  back.
- A sponsor covering or discounting that cost keeps the project alive
  and free for everyone else.

The second half matters too. Modern AI work means juggling many models
— some made locally, some abroad, some for chat, some for coding tools
like Claude Code or Codex. Having one place to reach them, instead of a
dozen separate accounts and bills, saves a lot of friction.

So the sponsorship is not decoration. It is the fuel: compute time and
model access that let volunteers build, test, and demo a demanding
real-time system.

## How does it work?

Here is the sponsorship in plain steps.

**1. The sponsor provides GPU rental.**

Imagine renting a super-powerful computer by the hour.

You pick the kind of graphics chip you need, the machine is prepared
quickly ("rapidly provisioned"), you run your AI training or demo on it,
and you are billed for what you used ("usage-based billing").

That is the core Compshare service described in the project: on-demand
GPU instances for model, algorithm, and application development.

**2. The sponsor provides model and API access.**

On top of raw machines, Compshare offers a one-stop shop for AI models.

Instead of signing up with every model provider separately, a developer
goes through Compshare to reach popular Chinese and international
models, including coding assistants such as Claude Code and Codex, or
calls the models directly through a programming interface (API).

Think of it like an app store for AI brains: one account, many models.

**3. New users join through an invitation link.**

The project points readers to a registration page with a built-in
referral code:

`referral_code=IBmJcGPVu1RF78dMihkQCX`

Clicking that link tells Compshare "this person came from CyberVerse,"
so the project gets credit for the referral.

**4. The project says thank you visibly.**

On the project page, the sponsor section is a small two-column table
inside an expandable block:

- On the left: the Compshare logo, about 150 pixels wide, which is
  itself a clickable link to the invitation page.
- On the right: a short thank-you note describing Compshare as UCloud's
  AI cloud platform, plus a "register through this invitation link"
  button leading to the same address.

It is a simple trade: visibility for the sponsor, resources for the
project.

## Where can this be used?

You do not need to be part of CyberVerse to understand the pattern. The
same setup shows up anywhere AI work is heavy:

- **Trying out a chatbot idea:** rent a GPU for an afternoon instead of
  buying one.
- **Training or fine-tuning a model:** scale up to bigger chips for a
  few days, then scale back down.
- **Building a voice agent or avatar demo:** combine rented GPUs with
  ready-made model APIs so you focus on the experience, not the wiring.
- **Coding with AI assistants:** reach tools like Claude Code or Codex
  through one platform account.
- **Running an open-source project:** thank a compute sponsor with a
  logo and referral link, the way CyberVerse does.

The general lesson: if your project is hungry for compute, a cloud
sponsor plus pay-as-you-go rental is often more practical than owning
hardware.

## Conclusions & takeaways

- CyberVerse is a free toolkit for real-time talking digital humans,
  built on voice chat, memory, tools, search, and optional video avatars.
- That kind of system needs a lot of GPU power, which is expensive to own.
- Compshare (优云智算), UCloud's AI cloud platform, sponsors the project
  with rentable GPUs and model API access.
- Developers get fast machines billed by usage, plus one place to reach
  many domestic and international models.
- The project returns the favor with a visible logo, a thank-you note,
  and an invitation link carrying its referral code.
- The bigger idea is simple: rented compute plus shared model access
  lets small open-source teams build things that would otherwise need a
  big company's hardware budget.
