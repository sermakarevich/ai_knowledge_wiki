## Contributor guidance
`CLAUDE.md` runtime boundaries, verbatim in substance (02-top-level-files.md:217-224):
- `TranscriptionEngine` loads models during startup and is shared within one process. `reset()` is for tests and backend comparisons.
- `AudioProcessor` is per session. `AudioInput` owns PCM buffering/decoding; `run_translation()` consumes translation events. Neither imports the orchestrator. Always call `cleanup()`.
- `WhisperLiveKitConfig` describes configuration. `parse_args()` returns this dataclass; `engine.args` is a compatibility namespace.
- `online_factory()` selects the session processor. Use `SessionASRProxy` or backend session wrapper for language/context overrides.
- `FrontData.to_dict()` defines native WebSocket JSON. Browser uses full snapshots; diff mode is opt-in.
- `translation_alignatt.py` connects to the separate AlignAtt4LLM translation server.

`Dockerfile.cpu` key lines, verbatim (02-top-level-files.md:398-479):
```
FROM ghcr.io/astral-sh/uv:0.12.10 AS uvbin
FROM debian:bookworm-slim AS builder-cpu
RUN uv python install 3.12
ARG EXTRAS=cpu
HEALTHCHECK --interval=30s --timeout=5s --start-period=120s --retries=3 \
  CMD python -c "import urllib.request; urllib.request.urlopen('http://localhost:8000/')" || exit 1
EXPOSE 8000
ENTRYPOINT ["wlk", "--host", "0.0.0.0"]
CMD ["--model", "tiny"]
```
Builder installs deps with `uv sync --frozen --no-install-project` then the package; runtime stage adds only `ffmpeg` and `ca-certificates` and copies `/python` plus `/app/.venv` (02-top-level-files.md:424-466).
