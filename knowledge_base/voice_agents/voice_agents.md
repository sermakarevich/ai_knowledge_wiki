# Voice Agents

Voice agents and speech-to-speech systems: full-duplex dialogue models, turn-taking and
interruption handling, latency engineering, TTS/STT components, voice-agent platforms
and harnesses, and speech benchmarks. Central thesis: real-time voice is a systems problem
— the model is one part, turn-taking, barge-in, and latency budgets decide production.
