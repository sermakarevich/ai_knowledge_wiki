# Brohammad/VoxForge

VoxForge is an open-source, self-hostable platform for building and operating enterprise voice agents. One `VoicePipelineService` unifies WebSocket, REST onboarding, and WebRTC transports behind a LangGraph orchestrator with knowledge RAG, tool use, per-turn evaluation, replay, and human handoff. This folder holds the summary, digest, wiki pages, explainer, critical analysis, and retrieval questions for the repo snapshot.
