# DeepL Voice: Real-Time Speech-to-Speech Translation
**In one sentence:** DeepL Voice is a production-grade cascaded real-time speech-to-speech translation system for business communication, launched in November 2024, that pairs proprietary real-time ASR with stable, low-latency translation streaming while end-to-end approaches are explored in parallel.
## Key points
- DeepL Voice follows a pragmatic incremental approach: a production-grade cascaded speech-to-speech translation (S2ST) system now, with end-to-end solutions explored in parallel.
- The production system launched in November 2024 and targets global business communication.
- Transcription quality is described as competitive, achieved through proprietary real-time ASR models.
- Translation "flickering" is eliminated via stable text streaming while maintaining low latency.
- The system supports 18 input languages and 30+ target languages.
- Three offerings are named: DeepL Voice for Meetings (Microsoft Teams/Zoom integration), DeepL Voice for Conversations (mobile apps), and the DeepL API for Voice.
- Business-appropriate communication is supported via customizable formality and glossary support.
- Voice-cloning text-to-speech (TTS) is under development and not yet released.
