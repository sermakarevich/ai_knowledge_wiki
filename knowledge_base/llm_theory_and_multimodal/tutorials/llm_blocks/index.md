# LLM building blocks — how each neural-network block works (intuition, code, plots)

A visual, hands-on tour of the parts that make up a modern LLM (large language model) such as
Qwen3.5 / Qwen3.8. Every block is (1) explained in simple language with an intuitive picture,
(2) implemented from scratch in a few lines of PyTorch, (3) checked against the reference
implementation in `torch` / `transformers`, and (4) illustrated with plots generated by the
project code (so every figure is reproducible). Everything runs on the Mac CPU in minutes —
no GPU needed. The sister tutorial `../llm_training/` uses these blocks to train and fine-tune
real models.

Retrieve with `ai show research_topics/llm_theory_and_multimodal/tutorials/llm_blocks` or `ai show research_topics/llm_theory_and_multimodal/tutorials/llm_blocks/03_attention`.

## Runnable project

`project/` — `uv` project (`pyproject.toml`, `justfile`, `src/llm_blocks/`, `tests/`). `just plots` regenerates all figures into `../assets/` (PNG, referenced from the chapters, 67 figures in total); `just test` runs CPU tests (< 2 min, no downloads); `just plots-real` runs the few plots that need the small real model (downloads once).

`specs/` holds the build instructions and research notes used by the fleet workers that wrote this tutorial (one spec per chapter, `COMMON.md` shared rules, `research/` sources with links). It is not part of the reading path.

## Shared settings

| Item | Value |
|---|---|
| Machine | Mac only, CPU. Never needs `rtx`. |
| Python / libs | Python 3.12, `torch>=2.13`, `transformers>=5.16`, `tokenizers`, `numpy`, `matplotlib`, `scikit-learn` (PCA only), `typer`, `rich`, `pytest` |
| Real model for plots | `HuggingFaceTB/SmolLM2-135M` (plain Llama-style transformer, 270 MB, for attention maps and embeddings) and `Qwen/Qwen3.5-0.8B` (hybrid Gated DeltaNet + attention, 1.6 GB, for chapters 03/07/10 "real" checks). Cached in `~/.cache/huggingface`. |
| Figures | `assets/NN_<name>.png`, generated by `uv run python -m llm_blocks.chNN_<module> plots`; 130 dpi; ≤ 300 KB each; every figure has a caption in the chapter explaining what to look at. |
| Tests | Each block implemented from scratch is compared numerically (`torch.testing.assert_close`) to the reference (`torch.nn`, `torch.nn.functional`, or the `transformers` Qwen3 / Qwen3.5 module with copied weights). |

## Conventions

- Chapters: "What you will learn" at the top, then sections, "Troubleshooting", "Exercises". 250–450 lines. Simple language; every abbreviation explained the first time it appears (also per chapter).
- Every formula is followed by a plain-English sentence and, where possible, a picture.
- Figures are never hand-drawn: if it is in the chapter, `just plots` produces it. Small diagrams may be Mermaid or ASCII inline.
- Code shown in chapters is copied from `project/src/llm_blocks/` and actually runs.
