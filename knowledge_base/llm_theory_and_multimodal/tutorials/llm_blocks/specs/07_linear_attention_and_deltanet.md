## Chapter — `07_linear_attention_and_deltanet.md`
Why softmax attention gets expensive (the n² figure; KV cache recap); linear attention: drop the softmax and the whole past compresses into one matrix (the state schematic; the RNN view — an RNN is a recurrent neural network: a loop that carries a memory); the catch: a fixed-size memory fills up and old memories interfere (retrieval-error figure); the delta rule = "before writing a new value for this key, erase what was there" (formula + plain sentence); gating = "let old memories fade" (figure); Gated DeltaNet = delta rule + gate + short convolution + output gate, as in Qwen3.5/3.8 (the block, our tiny implementation, the equivalence test result); why hybrid 3:1 (linear layers for cheap long-range memory, real attention every 4th layer for precise recall — the stack figure, the 70k memory numbers for the 27B); what changes on a GPU (`fla` chunked kernels; pointer to `../llm_training/03_model_from_scratch.md` benchmark); Troubleshooting; Exercises (change β to 1 → what happens; remove the conv; vary the ratio 3:1 → 7:1 and recompute memory).
