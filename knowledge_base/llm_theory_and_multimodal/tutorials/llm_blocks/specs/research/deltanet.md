# Gated DeltaNet — research notes for chapter 07

Sources: Yang, Kautz, Hatamizadeh, *Gated Delta Networks: Improving Mamba2 with Delta Rule*,
ICLR 2025 (arXiv:2412.06464); Qwen3-Next / Qwen3.5 / Qwen3.8 model cards;
`transformers==5.16.1` `models/qwen3_5/modeling_qwen3_5.py` (read on 2026-08-30).

## Formulas (per head; `S` is the `d_k x d_v` recurrent state)

1. Linear attention (Katharopoulos et al. 2020) — drop the softmax, keep a running sum:
   `S_t = S_{t-1} + k_t v_t^T`, `o_t = S_t^T q_t`. Equivalent parallel form
   `o = ((q k^T) ⊙ causal_mask) v`. Cost O(T·d²) instead of O(T²·d); memory is one fixed matrix.
2. Problem: `S` is a fixed-size associative memory. Writing key after key sums interference, so
   retrieval of an old key returns its value *plus* leakage from every other stored key.
3. DeltaNet (Schlag et al. 2021) — write with an *error-correcting* (delta) update:
   `S_t = S_{t-1}(I − β_t k_t k_t^T) + β_t k_t v_t^T`
   = `S_{t-1} + β_t k_t (v_t − S_{t-1}^T k_t)^T`. Read the old value for this key, subtract it,
   write the difference. `β_t ∈ (0,1)` = write strength; `β_t = 1` with `‖k_t‖=1` overwrites exactly.
4. Gated DeltaNet (this paper) — add Mamba2's scalar forget gate `α_t ∈ (0,1)`:
   `S_t = S_{t-1}(α_t (I − β_t k_t k_t^T)) + β_t k_t v_t^T`, `o_t = S_t^T q_t`.
   Gate alone (Mamba2) = "fade everything"; delta alone (DeltaNet) = "overwrite one key";
   together = targeted overwrite *plus* graceful decay of stale memory. Best of both on
   language modelling, in-context recall (MQAR/needle) and length extrapolation.
5. Chunked parallel form (what GPUs run): split T into chunks of 64, expand the product of
   `(I − β k k^T)` inside a chunk into a WY representation, so each chunk is a few matmuls.
   `fla` provides `chunk_gated_delta_rule` / `fused_recurrent_gated_delta_rule` Triton kernels.

## `transformers` reference (`qwen3_5`) — what we test against

- `l2norm(x)` = `x * rsqrt(sum(x²) + 1e-6)`; q and k are L2-normalised *inside* the kernel when
  `use_qk_l2norm_in_kernel=True` (Qwen3.5 always passes True).
- Both fallbacks scale `q *= 1/sqrt(d_k)` internally, and take `g = log α_t` (not α).
- `torch_recurrent_gated_delta_rule(q,k,v,g,beta,initial_state,output_final_state,...)` is the
  literal loop: `S *= exp(g_t)`; `delta = (v_t − S^T k_t)·β_t`; `S += k_t ⊗ delta`; `o_t = S^T q_t`.
- `torch_chunk_gated_delta_rule(..., chunk_size=64)` is the mathematically equal chunked version;
  it is what runs for a prefill (seq_len > 1) when `fla` is absent — as on this Mac
  (`fla` and `causal_conv1d` are both not installed).
- `Qwen3_5GatedDeltaNet.forward`: `in_proj_qkv` → transpose → depthwise causal `conv1d`
  (kernel 4, padding 3, groups = conv_dim, SiLU) → split into q/k/v → `beta = sigmoid(in_proj_b(x))`,
  `g = −exp(A_log) · softplus(in_proj_a(x) + dt_bias)` (so `α = exp(g) ∈ (0,1)`) →
  `repeat_interleave` q/k when `num_v_heads > num_k_heads` → delta rule →
  `Qwen3_5RMSNormGated(out, z)` = `RMSNorm(out) * silu(in_proj_z(x))` → `out_proj`.
