# OpenMOSS/MOSS-TTSD

MOSS-TTSD reframes synthesis as script-to-conversation: tagged dialogue scripts with 1–5 cloned voices rendered as continuous expressive audio up to 60 minutes per session. This folder distills the repository into a quick summary, a verbatim digest, and two deep-dive wiki pages. Start here to decide what to read next and where each detail lives.
