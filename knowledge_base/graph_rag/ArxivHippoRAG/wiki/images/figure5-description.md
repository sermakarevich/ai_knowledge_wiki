**Figure 5 — HippoRAG Pipeline Example (Retval)** is not a data plot with axes; it is a three‑panel vertical workflow diagram illustrating how the HippoRAG retrieval pipeline turns a natural‑language question into a ranked set of knowledge‑graph passages. The three stacked blocks correspond to sequential stages, and the only quantitative content is a small table of node‑probability values in the middle panel.

**Top panel — Query NER & Node Retrieval.** For the sample question *"In which district was Alhandra born?"*, a named‑entity recognizer extracts the entity *Alhandra*, and a retrieval encoder maps that query entity onto the corresponding knowledge‑graph node ("Alhandra" → node *Alhandra*). This is the seed/initialization step.

**Middle panel — Personalized PageRank (PPR) probability propagation.** This block lists how node probabilities shift from before to after PPR, i.e., the seed's initial probability mass (≈1.0 on *Alhandra*, ≈0 on all others) is redistributed across the subgraph. Approximate post‑PPR values: the seed *Alhandra* drops to a bit above 0.5, while its neighborhood picks up small but meaningful mass — *Vila Franca de Xira* to a few hundredths (the largest neighbor, ≈0.05), followed closely by *Lisbon*, *footballer*, *Portuguese*, *5 March 1979*, and *Luís Miguel Assunção Joaquim* (all in the low‑hundredths), with more distant nodes (*Portugal*, *Tagus River*, *José Pinto Coelho*) receiving only negligible mass. The trend is a clear distance/semantic decay: mass concentrates on the most tightly connected, context‑relevant nodes and falls off sharply for peripheral ones.

**Bottom panel — Passage‑level Top Results.** Node probabilities are aggregated over the passages in which each node appears to rank passages. The top‑ranked PPR nodes are highlighted (yellow) within the retrieved passages, and the ranking correctly places the *Alhandra (footballer)* passage first and the *Vila Franca de Xira* passage (the true answer to "which district") second, ahead of more generic pages (*Portugal*, *Huguenots*, *East Timor*).

**Takeaway.** The figure demonstrates the end‑to‑end retrieval mechanism: NER + node retrieval seeds the graph, PPR spreads that seed's probability through the subgraph so that semantically linked nodes (notably the answer entity *Vila Franca de Xira*) acquire non‑zero scores, and summing node scores over their passages yields a passage ranking that surfaces the correct answer near the top — evidence that PPR‑based neighborhood expansion improves retrieval over the raw query node alone.
