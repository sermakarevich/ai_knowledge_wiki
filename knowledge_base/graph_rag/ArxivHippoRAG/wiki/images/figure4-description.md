**Figure 4 – HippoRAG indexing pipeline (illustrative, not a quantitative plot).** The figure has no numerical axes or trends; it is a two‑panel schematic showing how the indexing stage turns text passages into a knowledge graph (KG).

**Top panel (per‑passage extraction).** For each of two example passages—*Alhandra (footballer)* and *Vila Franca de Xira*—it lists the two extraction outputs that are applied sequentially:
- **NER:** the set of named entities (e.g., for Alhandra: a date ~1979, the name, *Lisbon*, a full‑name alias, *Portuguese*, *Vila Franca de Xira*; for the place: a year ~2011, a person, a cave site, *French*, *Lisbon*, *Lisbon District*, *Portugal*, *Tagus River*).
- **OpenIE:** the (subject, relation, object) triples derived from the passage (e.g., *Alhandra → is a → footballer*, *Alhandra → born in → Vila Franca de Xira / Lisbon*, *Alhandra → born on → 5 March 1979*, *Luís Miguel Assunção Joaquim → is also known as → Alhandra*; and for the place, triples such as *is a municipality in → Lisbon District*, *situated on → Tagus River*, *had population of → ~136,886 (in 2011)*, *has area of → ~318 km²*).

**Bottom panel (resulting KG subgraph).** The same facts are drawn as a node–edge graph. Two hub nodes—**Alhandra** and **Vila Franca de Xira**—are connected to each other (*born in*) and to surrounding entity nodes via labeled edges (*is a, is, born on, is also known as, located in, is a municipality in, situated on, had population of, had area of, equivalent*). This shows how separate passages are unified: entities re‑occur as shared nodes, so attributes from one passage attach to the same graph node referenced from another.

**Takeaway.** Indexing = run NER + OpenIE on every passage to emit structured triples, then merge them into one open KG over the whole corpus. The relevant subgraph around a query entity (here Alhandra / Vila Franca de Xira) bundles multi‑hop attributes—identity, location, population (~10⁵), area (~10² km²), dates—so downstream retrieval can reason over connected facts rather than isolated sentences. Only the question‑relevant slice of the full KG is shown.
