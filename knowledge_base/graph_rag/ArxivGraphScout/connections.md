# Connections

- [[ai_papers/graph_rag/ArxivGraphReasoningAgentGRA/summary|Schema-Agnostic Graph Reasoning Agent (GRA)]] — same-problem-different-method: GRA gives an LLM agent seven generic unix-style tools to navigate a hybrid knowledge graph *without any RL training*, beating full-context schema serialization on an industrial benchmark at a third of the tokens. Directly contrasts with GraphScout's bet that training-free tool flexibility alone (PolyG-style) isn't enough and post-training is what closes the gap — worth reading together to see the training-free vs. training-centric split of the current agentic-GraphRAG field.
- [[ai_papers/graph_rag/graph_rag|GraphRAG category index]] — shares-technique: lists GraphCoT, PolyG, and GraphCounselor as canonical active-traversal-based baselines, all of which GraphScout benchmarks directly against and discusses in its Related Work and Discussion sections.
- AgentGL (arXiv:2604.05846, in-flight ingestion, not yet filed) — shares-technique: also RL-trains native graph tools instead of text-flattening the KG, reporting +17.5% node classification / +28.4% link prediction gains. A close sibling to GraphScout's "train the model, don't just prompt it" thesis, applied to different graph tasks (classification/link prediction rather than QA).
- PathRouter (arXiv:2606.16409, in-flight ingestion, not yet filed) — same-problem-different-method / critical counterpoint: explicitly studies reward hacking in RL-trained agentic graph retrieval (lucky-shortcut answers, uninformative step rewards) — directly relevant to assessing whether GraphScout's clue-based reward design (capped, gated by an answer-quality threshold) is robust to the same failure mode; GraphScout does not test this explicitly (see [[critical_thinking|Critical Analysis]]).
- Why Neighborhoods Matter (arXiv:2605.15109, in-flight ingestion, not yet filed) — shares-technique / complementary: argues answer trustworthiness in agentic GraphRAG depends on the whole traversal path, not just cited facts — the same intuition behind GraphScout's evidence-clue reward, from an evaluation-methodology angle rather than a training angle.
