# Connections

- [[ai_papers/graph_rag/ArxivHippoRAG/summary|HippoRAG]] — MemGraphRAG uses the same core retrieval primitive (Personalized PageRank over an LLM-built knowledge graph) but adds a persistent, conflict-resolving Global Memory at construction time; HippoRAG is in fact one of MemGraphRAG's strongest baselines (HippoRAG2 is the runner-up on most benchmarks), so this is a direct build-on relationship at the retrieval layer.
- [[ai_papers/graph_rag/ArxivLightRAG/summary|LightRAG]] — Another head-to-head baseline; LightRAG optimizes for cheap incremental updates via dual-level retrieval, which is exactly the streaming/incremental-corpus scenario MemGraphRAG's memory framing implies but never actually benchmarks — worth reading together to see what a construction-cost comparison would look like.
- [[ai_papers/graph_rag/ArxivGraphRAGLocalToGlobal/summary|Microsoft GraphRAG]] — The canonical clustering-based (Leiden community summarization) construction paradigm that MemGraphRAG explicitly critiques (Appendix B.2) for propagating low-level extraction errors upward through hierarchical summaries; MemGraphRAG's memory-based filtering is a direct alternative to this paradigm's error-propagation weakness.
- [[ai_papers/graph_rag/ArxivGraphRAGUnderFire/summary|GraphRAG Under Fire]] — Documents a different GraphRAG fragility (susceptibility to knowledge-poisoning attacks that exploit graph structure); read alongside MemGraphRAG's conflict-detection mechanism to ask whether provenance-grounded conflict resolution would also catch or resist adversarially poisoned facts, since neither paper tests that intersection.
- [[ai_papers/graph_rag/ArxivWhyNeighborhoodsMatter/summary|Why Neighborhoods Matter]] — A controlled ablation study on what actually drives agentic GraphRAG answer quality (graph structure and visited-but-uncited entities, not just final citations); complements MemGraphRAG's Appendix A.2 graph-topology claims (density, clustering) with a more rigorous causal framework for evaluating whether "denser graph" actually means "better answers."
- [[ai_papers/graph_rag/ArxivGraphRAGBench/summary|GraphRAGBench]] — A benchmark paper finding that GraphRAG's accuracy gains over vanilla RAG are inconsistent across question types and topics; provides useful outside validation for MemGraphRAG's own preliminary-study claim that GraphRAG can underperform vanilla RAG, from an independent benchmark rather than this paper's own pilot experiment.
- [[ai_papers/graph_rag/ArxivSodaMem/summary|SodaMem]] — A different memory-architecture answer to a related problem (evidence-grounded temporal memory with provenance and write-time supersession for LLM agents, rather than GraphRAG specifically); useful comparison point for the general pattern of "shared memory with provenance-grounded conflict/supersession handling" used across both agent-memory and GraphRAG-construction contexts.
