3.1
Task Formulation
We formalize agentic GraphRAG as a multi-turn
agent-environment interaction following Luo et al.
(2025a). Given a knowledge graph G constructed
from a document collection, an LLM-based agent
πθ interacts with a graph retrieval environment to
answer a query q. At each turn t, the agent ei-
ther emits a reasoning segment rt within <think>
tags followed by a search query qt within <query>
tags, or emits a final answer a within <answer>
tags to terminate the trajectory.
The environ-
ment processes qt and returns retrieved passages
within <knowledge> tags as the environment ob-
servation ot.
A reasoning trajectory is τ
=
((r1, q1, o1), . . . , (rT , qT , oT ), a), where T is the
number of retrieval turns.
Building on this formulation, PATHROUTER ex-
tends GRPO with a path-aware design. Trajecto-
ries are evaluated along answer correctness and
evidence-path overlap (EO) to modulate GRPO ad-
vantage scaling, distinguishing shortcut answers
from evidence-seeking ones. For evidence-poor
trajectories, a selective gold-evidence teacher pro-
vides token-level KL guidance on reasoning and
search-query steps without imitating final answers,
encouraging retrieval that is both answer-accurate
and evidence-faithful.

The route weight modulates update magnitude, and

• C ↑P ↑: Full weight (wfull). The answer is

• C ↑P ↓: Reduced weight (wdown). Answer is

trieval.
• C ↓P ↑: Attenuated weight (wpreserve). Evidence

is likely due to a final-reasoning failure. Atten-
uated weight mitigates over-penalizing useful
retrieval behavior.
• C ↓P ↓: Full weight (wfull). Both answer cor-
rectness and evidence overlap are low.
3.3
Distillation for Retrieval-Token
Route-conditioned scaling adjusts the magnitude
of policy updates but leaves each trajectory with a
single scalar advantage that does not specify which
search actions should change. For evidence-poor
trajectories (Pi < θP ) identified by the routing di-
agnostics in §3.2, we address this search-update
ambiguity by invoking a gold-evidence teacher
that provides token-level distributional supervision
on reasoning and search-query tokens, converting
trajectory-level evidence failure into localized guid-
ance for retrieval improvement. The teacher is used
only during training, whereas at inference the stu-
dent acts without any privileged information.
Inspired by Ye et al. (2026), we use the frozen
reference model as the teacher.
Crucially, the
teacher does not generate its own trajectory during
training, but instead scores the student’s on-policy
rollout under a privileged context. For each train-
ing sample (q, G, Sgt, a∗), the student first samples
a trajectory τi. At each token position t, both the
student and teacher condition on the same response
prefix r<t from this trajectory, differing only in
their respective prompt context:

3.4
Training Objective
Reward Design. The reward combines task com-
pletion with evidence-path quality and exploration
shaping:
R(τi) = ra + α rp + rs,
(8)
where ra = F1(ai, a∗) measures answer quality,
rp = Pi incorporates evidence-path overlap into
the reward signal, and rs aggregates exploration
shaping terms.
rs = re + rl + ro + rd.
(9)
The exploration bonus re rewards multi-turn re-
trieval for correctly-answered questions. The lazy
penalty rl penalizes single-turn stops with insuffi-
cient evidence coverage. The timeout penalty ro
penalizes reaching the maximum turn limit. The
redundancy penalty rd discourages re-retrieving
already-covered evidence.
