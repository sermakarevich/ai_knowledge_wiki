**Figure 1 – Two failure modes of a search-augmented reasoning agent (schematic pipeline, no data axes).**

The figure is not a plotted graph but a pair of horizontal workflow diagrams that contrast two ways an LLM agent fails (or superficially succeeds) on a multi-hop question — *"Who developed the statue of the person with the most finals MVPs in the NBA?"* — using node icons (Think, Search Query Generation, Retrieved Evidence, Memory Knowledge) joined by arrows, with red slashes marking broken search steps and a red "X" badge flagging each panel as a failure mode. A per-panel metric box reports an approximate **F1** (token-level overlap with gold evidence) and an **EO** (evidence-path overlap) value.

- **Panel (a) "Reasoning Failure":** The agent thinks, attempts search-query generation (marked failed), retrieves evidence, retries search, lands on a *Useful Evidence* node, yet still emits the wrong answer ("Bronze"). A "Guidance to Stop Searches" annotation sits below the chain. Metrics: **F1 ≈ 0**, **EO ≈ 0.0–0.1** (i.e., essentially no overlap with the true evidence path). Takeaway: insufficient/misleading evidence breaks the reasoning chain even when some evidence is retrieved.

- **Panel (b) "Shortcut Failure":** The agent thinks, generates a query, gets *No Useful Information*, *Repeats ×N*, then falls back on *Memory Knowledge* (parametric knowledge) to produce a *correct-looking* answer ("Rubin…Amory"). A "Poor Evidence" node and a "Guidance to Change Shortcut Searches" annotation appear. Metrics: **F1 ≈ 1.0** (answer matches gold) but **EO ≈ 0.0–0.1** (still near-zero evidence-path overlap). Takeaway: the model "cheats" via internal memory instead of grounding in retrieved evidence.

**Trend / core takeaway:** The two modes sit at opposite ends of the F1 axis (≈0 vs. ≈1) yet share a similarly low EO score. This demonstrates that a scalar outcome reward (correct/incorrect) is ambiguous — one failure is genuinely wrong, the other is right but ungrounded — so the same reward signal corresponds to *different* underlying failure mechanisms that require *different* mode-level corrective updates (stop searching vs. change shortcut searches). The figure's purpose is to motivate evidence-path-overlap (EO) as a diagnostic that disambiguates these modes better than the answer-level reward.
