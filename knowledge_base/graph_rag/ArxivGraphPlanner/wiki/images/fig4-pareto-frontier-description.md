**What it shows.** The page presents two comparison tables (Table 4 and Table 5) benchmarking the proposed *GraphPlanner* router against four baselines (GraphRouter, RouterDC, Router‑R1) in Phase‑2. Table 4 reports training efficiency (tokens used, GPU compute, average LLM training calls); Table 5 reports zero‑shot generalization accuracy on three unseen datasets (LogicGrid, M‑GSM, CommonGen) plus an average.

**Structure (in place of axes).** Because these are tables rather than plots, there are no continuous axes. Rows are the routers; columns are the metrics. Table 4's columns are categorical/numeric metrics (tokens, GPU memory in GiB, mean LLM calls); Table 5's columns are per‑dataset accuracy percentages and an average.

**Trends.**
- *Efficiency (Table 4):* Token usage splits into two regimes—GraphRouter and RouterDC use on the order of tens of millions of tokens (~65M), whereas Router‑R1 and GraphPlanner use far fewer (roughly 150k–200k). GPU memory is the more discriminating metric: GraphPlanner sits at the low end (~1 GiB), GraphRouter is low (~1.5 GiB), RouterDC is mid (~10 GiB), and Router‑R1 is by far the highest (~180+ GiB). Average LLM calls are ~1 for the first three but highest for GraphPlanner (~4). So GraphPlanner trades more LLM calls for much lower memory and low token cost.
- *Accuracy (Table 5):* GraphPlanner leads on every unseen dataset (~60% LogicGrid, ~90% M‑GSM, ~80% CommonGen) and has the highest average (~78%). RouterDC is second overall (~58% avg, strong on M‑GSM ~80% but weak on LogicGrid ~30%); Router‑R1 and GraphRouter trail, with Router‑R1 lowest (~38% avg). Gaps are largest on LogicGrid.

**Takeaway.** GraphPlanner is both more efficient and more accurate: it achieves the best zero‑shot generalization on unseen tasks while keeping GPU compute and token consumption at the lowest level (despite issuing the most LLM training calls), whereas the most token‑heavy or compute‑heavy baselines (Router‑R1, RouterDC) underperform it on both cost and accuracy. The headline message is that GraphPlanner reduces training overhead *and* improves unseen‑dataset performance relative to the compared routers.
