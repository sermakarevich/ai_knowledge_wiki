**Takeaway.** GraphPlanner casts workflow generation as a Markov decision process in which GARNet unifies two memory graphs—the live, step‑by‑step‑updated 𝓖_workflow and the end‑of‑episode‑consolidated 𝓖_history—to emit, at each step, an action that jointly selects *which LLM* and *which agent role* (planner / executor / summarizer) to act on the current query. The diagram's purpose is to make the data flow explicit: per‑step trajectories incrementally populate 𝓖_workflow, whole episodes are folded into 𝓖_history, and GARNet reads both to route the next action—enabling context‑aware routing and end‑to‑end RL optimization.
