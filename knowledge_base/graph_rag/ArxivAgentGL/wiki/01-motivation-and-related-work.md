# Motivation and Related Work

**In one sentence:** LLM agentic reasoning operates only on unstructured text and ignores the topology of real-world Text-Attributed Graphs, so AgentGL formulates graph learning as an RL-optimized, topology-aware navigation process — the first RL-driven Agentic Graph Learning framework, outperforming GraphLLMs and GraphRAG by up to 17.5% (node classification) and 28.4% (link prediction).

## Key points

- Central question: can the agentic learning paradigm (iterative retrieval, tool use, decision-making over external resources) be extended to graph-structured environments to enable dynamic, topology-aware reasoning — and how can such a system be built efficiently?
- Motivation: RAG and agentic search let LLMs move beyond static parametric knowledge, but they treat external information as flat text; in citation networks, social platforms, and commercial ecosystems, meaning arises from the interplay of text content and graph topology, which lexical-similarity agents cannot harness.
- Challenge C1 (topology-aware navigation): graph evidence is multi-scale — some clues live in tight local neighborhoods, others emerge only via broad structural patterns — so the agent must choose the next move in a combinatorial space while avoiding redundant or uninformative regions.
- Challenge C2 (long-horizon policy optimization): effective graph reasoning needs multi-step exploration, but ground-truth search trajectories are rarely available, making it hard to learn policies balancing exploration/exploitation/reasoning depth without drifting into irrelevant branches or wasteful tool calls.
- AgentGL's three mechanisms: (i) graph-native search tools — local neighborhood expansion, hop-constrained traversal, global evidence probing — for multi-scale exploration; (ii) search-constrained thinking, which biases the agent toward reflective inference before issuing further graph queries, balancing accuracy against efficiency; (iii) graph-conditioned curriculum RL that progressively raises topology-exploration difficulty, uses multi-faceted rewards, and enforces efficient tool use under limited budgets — learning without step-wise trajectory supervision.
- Position vs GraphLLMs: GraphGPT and GraphICL integrate LLMs with graph information via graph-guided prompting or instruction tuning, but rely on static graph context extracted once at inference time, preventing adaptive exploration.
- Position vs GraphRAG: these systems build large text-enriched knowledge graphs from corpora — costly to construct and lacking the native topological correlations of real TAGs.
- Results: across diverse TAG benchmarks and multiple LLM backbones, AgentGL delivers absolute accuracy improvements of up to 17.5% in node classification and 28.4% in link prediction over leading GraphLLM and GraphRAG baselines; code is public at github.com/sunyuanfu/AgentGL.

## The Problem

LLMs have achieved strong results across NLP through broad linguistic and reasoning capabilities, but parametric knowledge alone is insufficient for specialized or fast-evolving domains. RAG and recent agentic search frameworks close this gap by letting LLMs iteratively query external resources and weave retrieved evidence into a dynamic chain of thought. Yet these agentic paradigms operate almost exclusively on unstructured text, overlooking the relational structures that underpin many corpora. In critical domains — citation networks, social platforms, commercial ecosystems — information is naturally Text-Attributed Graphs (TAGs), where meaning is derived from the interplay between textual content and graph topology. Agentic systems relying solely on lexical similarity therefore cannot exploit these structural dependencies, which raises the paper's central question: can agentic learning be extended to graph-structured environments for dynamic, topology-aware reasoning, and how can such a system be built efficiently.

Existing graph learning only partially addresses the need. Traditional GNNs capture structural signals but struggle with rich textual semantics. Recent GraphLLMs (e.g., GraphGPT, GraphICL) integrate LLMs with graph information via graph-guided prompting or instruction tuning, yet their graph context is extracted once at inference time — static, so no adaptive exploration is possible. GraphRAG systems construct large text-enriched knowledge graphs from corpora, but these reconstructed KGs are costly to build and do not preserve the native topological correlations of real TAGs. Neither family offers a mechanism for dynamic evidence acquisition over real-world graph structure.

Agentic Graph Learning (AGL) is the emerging direction where an LLM agent autonomously navigates a graph, accumulates structural evidence, and iteratively refines its search trajectory based on on-the-fly reasoning. Realizing AGL is non-trivial due to two fundamental challenges. (C1) Topology-aware navigation: evidence is multi-scale — some clues appear in tightly local neighborhoods, others only through broader structural patterns — and the agent must decide where to go next in a combinatorial space while avoiding redundant or uninformative regions. (C2) Long-horizon policy optimization: graph reasoning frequently requires multi-step exploration, but ground-truth search trajectories are rarely available; learning a policy that balances exploration, exploitation, and reasoning depth is difficult, and agents easily drift into irrelevant branches or incur unnecessary tool calls. Addressing both demands a principled formulation of graph-native action spaces and stable training mechanisms for long-horizon decision-making.

AgentGL addresses these by formulating graph learning as an agentic decision-making process optimized via reinforcement learning. It equips the LLM with a suite of graph-native search tools — local neighborhood expansion, hop-constrained traversal, and global evidence probing — enabling multi-scale structural exploration tailored to the task. To prevent over-searching and encourage deeper reasoning on retrieved evidence, it introduces search-constrained thinking, a mechanism that biases the agent toward reflective inference before invoking additional graph queries. To support stable long-horizon learning without step-by-step trajectory supervision, it develops a graph-conditioned curriculum RL strategy that progressively increases topology-exploration difficulty, integrates multi-faceted rewards, and enforces efficient use of graph tools under limited budgets. Together, these components let LLM agents learn adaptive, topology-aware search policies across diverse graph reasoning tasks.

The contributions are threefold: (i) AGL itself, a new paradigm treating graph learning as an interleaved process of topology-aware exploration and LLM-based reasoning, unifying graph structure, text semantics, and agentic decision-making under one framework; (ii) AgentGL, the first RL-driven AGL framework orchestrating graph-native search tools and search-constrained thinking with graph-conditioned curriculum-based RL, policy learning without step-wise supervision; and (iii) broad TAG-benchmark evaluations showing absolute accuracy improvements of up to 17.5% in node classification and up to 28.4% in link prediction over leading GraphLLM and GraphRAG baselines, across diverse LLM backbones.

## Related Work

The related-work section draws two contrasts.

**Graph learning with LLMs.** Recent work bridges graph-structured data and LLMs in two lines. One textualizes local structures into natural-language descriptions to support LLM reasoning and contextualized representations. The other derives graph tokens or structure-aware embeddings injected into prompts for graph instruction tuning, or performs training-free inference via graph in-context learning. Despite progress, these pipelines are largely static, limiting adaptation when additional evidence is needed during inference time.

**Grounding LLMs with external knowledge.** Standard RAG improves factuality via static retrieval, while agentic search advances this with iterative reasoning through reinforcement learning or prompting — but these methods predominantly target unstructured text. GraphRAG approaches (e.g., He et al. 2024; Jimenez Gutierrez et al. 2024; Dong et al. 2025; Han et al. 2024) retrieve evidence from graph-structured data, yet they often rely on synthetic graphs reconstructed from flat corpora, and their task objectives are fundamentally different from graph learning. Even native-graph agentic methods remain limited: GraphCoT (Jin et al., 2024) focuses on graph QA, and GraphSearch (Liu et al., 2026) targets graph learning, but both rely on heuristic prompting with limited optimization, often yielding sub-optimal solutions.

AgentGL differs from both lines: its graph context is acquired dynamically at inference time by an agent navigating the *native* TAG (rather than a reconstructed KG or a single static context snapshot), and its navigation policy is learned end-to-end with RL and a curriculum rather than fixed heuristic prompting.
