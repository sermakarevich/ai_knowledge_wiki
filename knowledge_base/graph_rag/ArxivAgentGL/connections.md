# Connections

- [[ai_papers/graph_rag/ArxivGraphScout/summary|GraphScout: Empowering LLMs with Intrinsic Exploration Ability for Agentic Graph Reasoning]] — shares-technique / close sibling: GraphScout also trains (via GRPO) a small LLM to use a structured toolset for graph exploration instead of prompting or flattening the graph into text, but targets knowledge-graph QA rather than node classification/link prediction. Both papers make the same core bet — "train the model to use graph-native tools, don't just prompt it" — for different task families; worth reading together to see the training-centric wing of the agentic-graph-reasoning field.
- [[ai_papers/graph_rag/ArxivGraphReasoningAgentGRA/summary|Schema-Agnostic Graph Reasoning Agent for Hybrid Knowledge Graphs]] — same-problem-different-method / critical counterpoint: GRA gives an LLM agent generic unix-style tools over a hybrid knowledge graph *without any RL training* and still beats full-context serialization. AgentGL's ablations (e.g., the coverage-reward collapse when removed) are relevant evidence for assessing whether GRA's training-free approach would hold up on AgentGL's node-classification/link-prediction tasks, or whether those tasks specifically need the RL-learned stopping/coverage behavior GRA does not have.
- [[ai_papers/graph_rag/ArxivWhyNeighborhoodsMatter/summary|Why Neighborhoods Matter: Traversal Context and Provenance in Agentic GraphRAG]] — complementary, evaluation-angle: argues that answer trustworthiness in agentic GraphRAG depends on the *whole traversal path*, not just the facts cited at the end. AgentGL's search-constrained thinking (rewarding dense reasoning between searches) and GCCL curriculum are training-side mechanisms aimed at the same underlying concern — making sure the agent's path through the graph is informative rather than noisy — from the opposite (training vs. evaluation) side of the problem.
- `papers/ArxivPathRouter` (arXiv:2606.16409, in-flight ingestion, not yet filed into `ai_papers/graph_rag/`) — same-problem-different-method / critical counterpoint: studies reward hacking in RL-trained agentic graph retrieval (lucky-shortcut answers, uninformative step rewards). Directly relevant to AgentGL's own reward design (r_COV, r_depth, r_FMT) — AgentGL's ablations show what happens when individual reward terms are *removed*, but does not test whether its combined reward can be gamed via shortcut trajectories the way PathRouter documents for other systems; a natural follow-up check for anyone adopting AgentGL's reward scheme.
- `ai_papers/graph_rag/graph_rag.md` (category index) — shares-technique: the broader GraphRAG survey/category page frames the static-retrieval-vs-native-topology tension that motivates AgentGL's Related Work section (its contrast with GraphRAG systems that reconstruct a knowledge graph rather than searching the native TAG).
