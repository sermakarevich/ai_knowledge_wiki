**What the figure shows.** Figure 1 is not a quantitative plot—it has no axes, no trend lines, and no numeric values—so "axes/trends/numbers" do not apply. It is a set of three side‑by‑side schematic flow diagrams (a baseline and two ablated variants) of an *agentic GraphRAG* pipeline, as stated in the caption ("the three agentic graphRAG systems we test in our experimental design"). Each panel shares the same backbone: a **User** issues a *Query* to a central **agent** (monitor icon); the agent can call **Tools** and read from a **Knowledge Graph** (a small directed node‑link graph, ~6 colored nodes); and the agent ultimately emits an **Answer + citations** document. The panels differ only in the *discipline imposed on the final answer step*.

**The three variants (left → right):**
1. **Agentic GraphRAG (pink)** – baseline. The agent freely transitions between Tools, Knowledge Graph, and a *Submit Answer* action that produces the answer with citations. No explicit check on the grounding of the answer.
2. **Evidence‑First Agentic GraphRAG (orange)** – the agent must first *Submit citations* (citations document with magnifier) before the answer is produced, i.e., evidence must be assembled and committed prior to the answer.
3. **Visited‑Only‑First Agentic GraphRAG (yellow)** – a verification gate is added: after producing a candidate answer, a decision node asks *"Are cited articles visited?"* If **No**, control loops back to the agent; only on **Yes** is the answer submitted. This enforces that every cited source was actually inspected.

**Takeaway.** The figure is a design/ablation schematic, not a result plot: it isolates *how* the answer‑generation step is constrained—unconstrained (baseline), citation‑first (evidence must precede the answer), or visitation‑gated (cited items must have been visited)—while holding the query → agent → {tools, knowledge graph} → answer core constant. The expected experimental contrast (per the caption) is between these three citation/verification regimes; the actual performance trends would appear in separate quantitative figures, not here.
