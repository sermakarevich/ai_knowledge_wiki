**Figure 2 — What it shows.** A qualitative, categorical comparison (not a quantitative plot) of how three different *graph‑ablation* regimes reshape a small synthetic entity‑relation subgraph. Each of the four panels draws the same underlying node‑link directed graph, with node colour encoding the entity's retrieval status: **green = cited**, **blue = visited but not cited**, **red = not visited** (per the caption). The panels are: *Original graph* (pink), *Visited‑but‑uncited entities ablation* (green), *Cited Entities Ablation* (yellow), and a smaller *Isolation* view (blue).

**Axes / trends.** There are no axes and no numeric trends to read; the figure is a set of schematic graphs whose "trend" is structural — i.e., which nodes and edges survive each ablation. Reading the panels against one another:

- **Original:** full connected subgraph spanning ~7 entities (e.g., *Peaky Blinders*, *Oppenheimer*, *Cillian Murphy*, *Dunkirk*, *Robert Downey Jr.*, *Christopher Nolan*, *Memento*) with directed edges linking them through the cited (green) hubs.
- **Visited‑but‑uncited ablation:** the blue node (*Christopher Nolan*) and its incident edges are dropped, so cited nodes (*Oppenheimer*, *Cillian Murphy*, *Dunkirk*) remain but downstream red nodes (e.g., *Memento*) become isolated/disconnected.
- **Cited‑entities ablation:** all green nodes are removed, leaving only the non‑cited nodes (*Robert Downey Jr.*, *Christopher Nolan*, *Peaky Blinders*, *Memento*) and a single remaining edge — i.e., most of the structure collapses.
- **Isolation:** only the mutually connected cited (green) subgraph is retained (*Oppenheimer* → *Cillian Murphy* ← *Dunkirk*).

**Takeaway.** The ablations are mutually complementary surgical operations on the same subgraph: removing cited entities strips out the core "evidence" nodes and fragments the graph, removing visited‑but‑uncited entities cuts the bridges that connect cited nodes to uncited ones, and the isolation view extracts just the cited‑entity core. Together they illustrate how a model's attention to different entity classes (cited vs. visited‑uncited vs. unvisited) corresponds to distinct, identifiable substructures of the knowledge graph, which is what the ablation study is intended to probe.
