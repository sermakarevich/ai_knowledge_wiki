# Connections

- [[agent_memory/GraphBasedAgentMemory/summary|Graph-based Agent Memory: Taxonomy, Techniques, and Applications]] — a survey that frames all agent memory as special cases of a graph, organized around an extraction→storage→retrieval→evolution lifecycle; SodaMem is a concrete instance of that lifecycle with its own specific choices (mandatory provenance, three temporal axes, write-time supersession) that the survey's taxonomy would classify but doesn't itself propose.
- [[graph_rag/ArxivHippoRAG/summary|HippoRAG]] — the canonical OpenIE-triples-plus-Personalized-PageRank graph memory; SodaMem explicitly positions itself against this line of work, replacing single-signal graph-walk retrieval with multi-tunnel connection-density fusion and adding the provenance/temporal machinery HippoRAG lacks.
- [[agent_memory/GaamaGraphAugmentedAssociativeMemoryForAgents|GAAMA: Graph Augmented Associative Memory for Agents]] — the closest direct comparator: also a concept-mediated hierarchical knowledge graph with hybrid PageRank+semantic retrieval evaluated on LoCoMo (78.9%), showing particularly large gains on temporal and multi-hop questions — the same failure modes (P2, P4) SodaMem targets, via a different fusion mechanism (edge-type-aware PPR vs. connection-density).
- [[agent_memory/StructMem/summary|StructMem]] — structures memory as events with dual-perspective extraction and periodic cross-event consolidation rather than a persistent graph, explicitly trading full graph connectivity for speed (~18× fewer tokens than graph-based baselines); a useful contrast to SodaMem's bet that graph structure and provenance are worth the extra overhead.
- [[agent_memory/ZeroMem/summary|ZeroMem]] — also builds a non-generative temporal structure (entity-context graph plus a four-level temporal hierarchy) to avoid LLM calls in memory *operations*, sharing SodaMem's emphasis on temporal structure as a first-class citizen but optimizing for zero-token memory maintenance rather than provenance-checked extraction.
- [[papers/NapMem/summary|NapMem]] *(unfiled, papers/)* — reframes memory access itself as an agent-controlled action space (search/get/read tools over a four-level pyramid) trained via RL, directly analogous to SodaMem's planner–reader loop but trained rather than prompted, and evaluated on the same family of benchmarks (LongMemEval, LoCoMo) that SodaMem uses.

Note: three other recently-ingested, closely-themed papers — `ArxivSAGEGraphMemory`, `ArxivMemGraphRAG`, and `ArxivPersonalAI20` — are visible under `papers/` but still mid-pipeline (wiki drafted, no `summary.md` yet), so they aren't linked here to avoid pointing at files that don't exist yet; worth revisiting this file once those finish ingestion, as their titles suggest direct overlap with SodaMem's temporal-graph-memory theme.
