# Connections

- [[research/PaperReplication/summary|Coding-agents can replicate scientific machine learning papers]] — the closest match in the KB: a separate paper (Hans & Bilionis, 2026) that also treats paper replication as an agentic-coding target, but via a persistent-workspace / formal completion-gate harness (target-level evidence bundles, externally checked) rather than an RL-trained judge-and-reward pipeline. Worth reading together: that paper solves "how do we know an agent actually finished replicating" with harness engineering, while this paper solves "how do we grade and train on replication quality" with an LLM rubric judge — the two problems (completion verification vs. quality scoring) are complementary parts of the same overall replication-agent design space.
- [[research/RoPoLLRobustPanelOfLLMJudges/summary|RoPoLL: Robust Panel of LLM Judges]] — directly relevant to this paper's rubric-judge design: RoPoLL addresses making LLM-judge panels robust and low-noise, the same underlying problem (judge reliability as an RL reward signal) that this paper solves in a domain-specific way (task-specific rubrics validated against human rankings) rather than a panel-of-judges approach.
- [[research_topics/training_and_self_evolution/training_and_self_evolution|Training & Self-Evolution category]] — this paper's modified-GRPO, turn-level-credit-assignment recipe for long-horizon, non-verifiable RL sits in the same territory as [[research_topics/training_and_self_evolution/LongHorizonLLMTraining/summary|LongHorizonLLMTraining]] (task-horizon length as an independent RL bottleneck, solved there via macro actions/subgoal decomposition rather than judge-based turn credit) — both papers attack the same "long multi-step rollouts destabilize RL" problem from different angles.
- [[research/TowardsAutomatingScientificReview/summary|Towards Automating Scientific Review with Google's Paper Assistant Tool]] — adjacent AI-for-science-process work: automating peer review rather than replication, but shares the broader theme of using LLMs to formalize and scale a traditionally human, judgment-heavy part of the scientific process.
- [[research/ForecastingScientificProgressWithAI/summary|Forecasting Scientific Progress with Artificial Intelligence]] and [[research/AutoResearchClaw/summary|AutoResearchClaw: Self-Reinforcing Autonomous Research with Human-AI Collaboration]] — both part of the broader "AI Scientist" literature this paper explicitly positions itself against (Section 2's critique of hard-coded test-time-scaling AI-Scientist systems and peer-review-style LLM judges); worth a comparative read to see how differently teams are approaching autonomous/AI-assisted research beyond replication specifically.

No entries in the KB yet directly cover the "coding-agent-as-tool" (CAT) orchestration pattern (small trained model directing a larger frontier coding agent) as its own topic — this may be worth a dedicated category note if more papers using this pattern get ingested.
