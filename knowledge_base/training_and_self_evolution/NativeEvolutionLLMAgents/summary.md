# Training LLM Agents for Spontaneous, Reward-Free Self-Evolution via World Knowledge Exploration

**Paper:** [Training LLM Agents for Spontaneous, Reward-Free Self-Evolution via World Knowledge Exploration (Zhang et al., 2026)](https://arxiv.org/abs/2604.18131)

## Human Readable TL;DR

Imagine hiring a new employee and, before their first task, they spend time wandering the office, reading the company wiki, and building their own mental map of how things work -- entirely on their own initiative, no manager needed. This paper teaches AI agents to do exactly that: explore an unfamiliar website or environment before being given any job to do, build a little "field guide" of what they found, and then use that guide when actual tasks arrive. The result is that even smaller, cheaper AI models can outperform much bigger ones, because having the right map matters more than raw intelligence.

## TL;DR

This paper introduces **Native Evolution**, a paradigm that trains LLM agents to spontaneously explore novel environments and distill observations into structured **World Knowledge (K)** -- a Markdown document -- before any task is assigned, without reward signals or human guidance at inference time. Training uses an outcome-based reward (performance delta on downstream tasks) and a two-stage pipeline (SFT with teacher trajectories + Reinforcement-based Rejection Sampling). On WebWalker and WebVoyager benchmarks, the approach yields ~19% absolute accuracy gain and 17% efficiency improvement; World Knowledge also transfers across model families, enabling compact models to outperform larger unassisted ones.

---

## Problem & Motivation

Existing "self-evolving" agents depend on human-defined tasks, engineered reward functions, or orchestrated adversarial workflows to improve. This external scaffolding means the agent cannot evolve in a truly novel environment -- if no one has pre-designed the task structure, the agent is helpless. The gap: agents lack **native curiosity**, the ability to proactively build an internal understanding of an environment before being told what to do. This is identified as the core bottleneck separating current agents from general-purpose autonomous intelligence.

## Main Original Ideas

1. **Native Evolution Paradigm** -- A two-phase life cycle: (1) a task-free *Native Evolution Phase* where the agent autonomously explores and produces World Knowledge `K`; (2) a *Knowledge-Enhanced Execution Phase* where `K` informs downstream task execution. No rewards or tasks exist in phase 1 at inference time.

2. **World Knowledge as an External Context Module** -- `K` is a compact Markdown document encoding the environment's structure (key pages, navigation patterns, important content). It is injected into the agent's prompt at execution time, making it compatible with any existing agent architecture without weight updates.

3. **Outcome-Based Reward for Task-Free Exploration** -- Training signal is defined as `R_evolve(K) = Success(T_E | K) − Success(T_E | ∅)`: the performance delta on downstream tasks *caused* by having `K`. This allows training without per-step labels during the exploration phase itself.

4. **Two-Stage Training: SFT + Reinforcement-based Rejection Sampling (RFT)** -- Gemini-2.5-Pro generates expert exploration trajectories; best `K*` per environment (selected by downstream accuracy) forms the SFT corpus. RFT then refines the policy over two iterations by keeping only the highest-utility exploration trajectories discovered by the model itself.

5. **Graph-Based Website Pre-processing** -- Websites are modeled as directed graphs; pages are scored by in/out-degree importance and clustered by URL prefix. This structured view reduces the cognitive load of exploration and is provided to the agent as `G(U)`.

6. **Meta-Learning-Driven Evolution Paradigm** -- Positions the approach as a third paradigm beyond Experience-Driven and Adversarial Evolution, targeting "workflow-free and reward-free" self-evolution via meta-learning.

## Key Findings

| Setting | WebWalker Accuracy | vs. Without K |
|---|---|---|
| Without K (baseline) | 22.04% | -- |
| Prompt-only Base (no training) | worse than baseline | negative |
| Prompt-only Gemini-2.5-Pro teacher | 29.85% | +7.8% |
| **Ours SFT** | ~35% | ~+13% |
| **Ours RFT (final)** | **40.91%** | **+18.9%** |

- **17% efficiency gain**: agents with `K` reach answers in fewer steps (acts as a "cognitive map").
- **Noise bottleneck**: untrained models producing their own `K` perform *worse* than no knowledge -- training is necessary to filter noise from genuinely useful exploration.
- **Cross-model transfer**: `K` generated by Seed-36B boosted Qwen3-14B by +18.3% and Kimi-K2-Turbo by +21.0% without any fine-tuning of those models.
- **Compact > large (with K)**: Qwen3-14B + K (35.6%) outperformed unassisted Gemini-2.5-Flash (31.3%) on the Conference domain.
- **Context length sensitivity**: gains plateau and slightly reverse beyond 16k--32k token `K` budgets due to noise dilution.
- **Ablation**: SFT + RFT1 provide the majority of gains; RFT2 yields marginal additional improvement.

## Suggestions & Future Directions

1. **Scaling exploration capacity** rather than model parameters as the primary lever for agent performance improvement.
2. **Extending to non-web environments** -- the paradigm is domain-agnostic in principle; applying it to codebases, databases, or physical simulators is a natural next step.
3. **Longer context utilization** -- improving models' ability to use very long `K` documents without noise degradation.
4. **Reducing teacher dependency** -- the SFT stage relies on Gemini-2.5-Pro trajectories; developing self-bootstrapping methods would remove this constraint.
5. **Dynamic/streaming K** -- current `K` is generated once pre-task; maintaining a live-updated world model during task execution is an open problem.
6. **Broader AGI implications** -- authors frame spontaneous environment understanding as a foundational capability toward AGI.
